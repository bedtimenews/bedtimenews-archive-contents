大家好，2026年4月28日星期二，欢迎收看1048期睡前消息。上次专门回顾老朋友还是985期节目，现在又是几个月过去了，我们再看看老朋友的近况。请静静读一下上周的新闻。

<font color = "indigo">国家中医药管理局原局长于文明涉嫌受贿一案，由国家监察委员会调查终结，移交检察机关审查起诉。</font>

去年12月16日，国家监委的立案信息更详细，也请静静读一段。

<font color = "indigo">违规收受礼品、礼金，利用职务上的影响为亲属经营活动牟利，将医药领域公共资源异化为谋取私利的工具，大搞隐形腐败，大肆收钱敛财；利用职务便利，为他人在药品注册审批、产品注册证书延期等方面牟利，并非法收受巨额财物。</font>

于文明给哪些中药审批提供了额外的方便？但从公开报道来看，于文明和以岭药业的院士吴以岭的私交非常好，多次以中医药管理局长的身份支持以岭药业的活动。从以岭药业自己的网站来看，最早在2013年，于文明就来过以岭药业，市场总经理吴相君陪同。另外，用"于文明"做关键的搜索，以岭药业的网站上至少还介绍了两次与其相关的重大活动，我就不再具体读了。

这还不是于文明给以岭药业的全部支持。之前节目提到过，以岭药业全部的理论基础，来自吴以岭在21世纪开创的一个新学派——络病学。为了在中医圈建立地位，为了给医生一个来药厂直接谈业务的聚会机会，以岭药业每年最重要的活动是举办络病学大会，于文明就是络病学大会最重头的嘉宾。比如说2019年的大会在北京国际会议中心开，于文明是参会列表第一名。到了2025年第21届，络病学大会改到上海召开，于文明以中华中医药学会会长的身份，变成了大会的主办方。请静静帮我读一下去年的于文明发言。

<font color = "indigo">中华中医药学会会长于文明在2月22日举行的第21届国际络病学大会上致辞时表示：络病学的发展，不仅为中医药防治心脑血管疾病、糖尿病、呼吸系统疾病等重大疑难病症提供了新的思路和方法，也为中医药现代化及中医药走向世界注入了强大动力。</font>

于文明提到了呼吸系统和中医药走向世界这两个概念，立刻勾起了新冠疫情期间的回忆。2022年封城期间，保安给我发了唯一的防疫物资：连花清瘟胶囊。同时中央和地方媒体集体宣传中药可以治疗新冠肺炎，重点是推荐连花清瘟，其中包括了人民网旗下的人民资讯。当时我连续做了五六七期节目公开辟谣，说各家媒体集体编造了世卫组织的观点。各位可以重新看一下417期睡前消息，以及后面的422期、430期，这几期节目至今还在平均播放量超过百万。这一切的起因是2022年3月，国内媒体恶意修改了世界卫生组织关于中医药抗菌新冠肺炎专家评估会的结论。请静静再读一下当时上观新闻的报道。

<font color = "indigo">评估会上，中国国家中医药管理局局长于文明对世卫组织持续支持传统医学表示欢迎，并表示，中国愿意协助其他世卫组织成员国加强传统医学在其卫生系统中的作用。该试验纳入了中国9个省份23家医院的284名患者，给予中药连花清瘟胶囊治疗。据报道，总体来看，与未给予中药干预的患者相比，服用该药的患者症状恢复时间更短。</font>

这些新闻可以确认，于文明确实是以岭药业、尤其是连花清瘟这种药的老朋友。从公开履历看，于文明是80年代山东中医学院的毕业生。离开学校之后，他没有当过一天医生，就去了中国中医药报社。在当国家中医药管理局的副局长之前，于文明一直是我的同行。现在回头看看当时的所谓世卫组织支持连花清瘟治疗新冠事件，确实完全是一个媒体人操作的传播学事件，和医学没有什么关系。前面最高检察院的文件还有一段话，请静静再读一下。

<font color = "indigo">检察机关起诉指控：被告人于文明利用担任国家中医药管理局副局长职务上的便利，以及职权或者地位形成的便利条件，为他人谋取利益，非法收受他人财物数额特别巨大，依法应当以受贿罪追究其刑事责任。</font>

于文明后来当过中医药局的正局长，但是起诉文件明确说，问题出在副局长任期之内。现在我就等着于文明的判决书上网了。

不知道有多少观众还记得，2023年出圈的淄博烧烤。我当时参加直播，给出了很不客气的评价：就是烧烤到目前为止还是一种劳动力比较密集的产业，它也是需要有这种半熟人社会形成之后，然后大家又从一些地方、一些企业或者是下岗或者是破产出来，又不想离开家乡，这个时候才会供给这种廉价烧烤。我见过鹤岗，对吧？我见过锦州，然后现在又轮到淄博了。我还是这句话：首先我希望我们国家再也不要有烧烤红的地方了，因为烧烤红的地方，日子过得长期看来都很惨。简单来说就是繁而不荣。我们经常都是繁荣，对吧？用繁荣形成一个社会。什么叫做繁荣？首先是繁，就是星星点点的到处都在开店；然后荣是什么？这些店都能赚到钱。然后我见到太多的地方繁而不荣，而且这种典型的地方，就是不断衰弱自己优势的老工业区。我在当年的铁西区，那个沈阳铁西区，我看到第一感受是什么：怎么开了这么多店？就是每一家都把自己的阳台推倒，然后就开了一家店。但是这样的店能赚钱吗？因为用脚趾头想也知道，它是赚不了钱的。现在呢，淄博也是这个情况。淄博好的一面，是它的工业没有完全倒，或者周围的县域经济还没有完全倒；淄博坏的一面，是已经被最近几轮在产业升级中被甩下，再加上被环保打击，两个重拳打得有点晕。在正在半晕不晕的时候，大家涌进去吃烧烤。但是你们五年十年前也是这么涌进锦州的。我就不说鹤岗了，鹤岗说实话也当过网红，你们现在对鹤岗还保有当时的怜悯吗？你们连可怜都不可怜他，对不对？锦州现在衰退成什么样？锦州过去是有个大铁路局的，不是铁路分局的。你们现在有谁在意锦州繁荣不繁荣？你们也不在意。淄博也是一样子的。

这次直播内容起源是2023年4月12号，我在知乎发过一篇当面泼冷水的回答，现在值得重新读一遍：鹤岗、锦州、淄博，各地领导可长点心吧，千万别盼着烧烤经济出圈。每一滴油都是产业升级被甩下的不甘心，每一块肉都是居民缺乏全职工作的无奈，每个网红都是地方经济主观的耻辱答案。成都钢管厂的串串出名，难道是因为无缝钢管造得好吗？那是因为大下岗。

三年时间过去了，现在我可以用淄博的例子，直接来解释这个"地方经济主观的耻辱答案"是什么了。请静静读一下4月24日中纪委通报的违反中央八项规定精神典型问题，只读第一条就行。

<font color = "indigo">重庆市政府原党组成员、副市长江敦涛，政绩观严重偏差，急功近利、盲目蛮干，接受可能影响公正执行公务的宴请和旅游活动安排等问题。2019年至2022年，江敦涛担任山东省淄博市委书记期间，为早出政绩、快出政绩，强势推进金融招商，未经评估论证和集体研究，违规引入私营企业主，安排国有企业融资，并设立政府引导基金由私营企业主导使用，因疏于监督管理，造成巨额国有资金损失风险；鼓吹政府不举债就是不作为，明知财政可支配收入不足，强推硬上多个项目建设，导致新增巨额地方债务。</font>

一直到2022年12月，江敦涛都是淄博的书记。2023年1月，他到了重庆当副市长，身后的淄博不仅有逾期支付的城投债，还产生了全国独一无二的专有名词：伪城投。在他离开几个月之后，淄博烧烤上了热搜。这不一定是文旅部门买流量替他遮掩问题，这是再次证明了一个规律：没有明显旅游资源的地方莫名其妙出了圈，多半背后有无法解决的财政难题。

最近几年，和淄博烧烤一样莫名其妙火起来的旅游概念，还有天水麻辣烫。2024年1月15日，天水被中纪委通报了：借钱投资90亿建设有轨电车，每年的运营成本是4000万，收入是160万。不到一个月的时间，2024年2月13日，天水麻辣烫成为全网的热搜。看来天水当地吸收了淄博的经验，引导舆论方向的效率是越来越高了。

2023年663期节目讨论了广州旧城改造的房票政策，这里先回顾一下当时的评论。房票就是地方政府印刷的代金券，在发放和回收两个层面都给地方政府带来好处。发放的时候节约现金，不用求银行贷款，不用到市场上借债，也能把土地顺利买下来。回收的时候，房票有指定的消费范围，肯定不能到本市之外去买房子，也不能不买房子，必须在指定的范围、指定的时间消费，可以保证新建的房子有人买。地方政府印刷代金券，原因当然是缺钱。市场不相信房价继续暴涨，而央行和财政部也不愿意继续发房地产贷款强行托市。对于已经产生了巨大房产泡沫的中国来说，这倒也是个好消息。广州这样的一线城市都要印代金券，说明至少到目前为止，国家并没有全面放水的意思，没有保护泡沫的意思。但国家不印钱，也不能由着地方政府随便印。从央行的角度来看，政府发出的房票毫无疑问是有价证券，甚至可以说是地方货币。和货币相比，房票缺乏监管和抵押程序，非常容易滥发，或者是做出过度的承诺。如果几年之后闹出事情，还是要中央财政来补窟窿。

三年时间过去了，请静静读一下中国新闻周刊4月24日的最新报道。

<font color = "indigo">但随着核发房票越来越多，其中一部分流向了市场。有当地村民告诉中国新闻周刊，不少旧改村民在本地已经有不止一套住房，想要购买新房的意愿较低，加上市场前景不明朗，所以愿意以远低于房票票面的价格转让房票。最近广州黄埔区传来房票暂停转让的消息，部分房产自媒体博主称，广州黄埔的房票转让已经暂停了，除了村民本人使用，其他转让都被认为无效。中国新闻周刊向负责核发黄埔区房票的黄埔安居集团广州有限公司咨询，相关工作人员表示，从今年1月21日开始，黄埔区房票的转让工作已经暂停，但并不影响旧改村民使用手中房票购买住房，村民的直系亲属也可以直接使用房票。关于后续房票转让的相关政策，目前还在制定中，之后会发布公告。</font>

房票是地方政府发行的代金券，如果不能自由转让，是一个非常危险的信号。因为当初发房票，已经是一次预支的政府信用，现在如果随便修改房票对应的权利，恐怕这房票只能发一次，甚至这还跨区剥夺了其他地方政府发房票的权利。

今年1005期睡前消息的标题是《华谊兄弟，走投无路》，我直接回顾当时最后的结论：如果反不正当竞争法能够落实到文化领域，未来中国的电影和其他视频市场可能会慢慢回归正常，逐渐地减少补贴，培养用户的付费习惯，也给生产内容的企业提供更多的空间。但是华谊兄弟这种急着越界赚钱的畸形企业，肯定是等不到那一天了。4月23日晚间，华谊兄弟公司发布公告，表示公司已经收到了金华中级法院做出的破产申请决定书，决定对公司启动预重整。

睡前消息988期的标题是《2.8万退休金，换安化黑茶》。当时我用百度搜索框的联想词做例子，现在我再试了一遍，发现还是会有很多人去交2.8万的加盟费，当然也有很多人担心是骗局，希望能够把自己的2万8拿回来。与此同时搜索黑茶，已经有人在关心收别人的2万8要判几年了。目前安化黑茶的官方定性，还停留在2月12日安化县政府的通报。在这之后，央视还继续播出了安化黑茶的广告。请静静帮我读一下安化理想华莱公司之前的宣传稿。

<font color = "indigo">在理想华莱，理想华莱茶养人生品牌广告强势登陆中央电视台四大频道，以国家级媒体平台为载体，向全国观众传递黑茶文化魅力。打响品牌声量的重要节点，10月10日，中央广播电视总台社教节目中心制片人莅临理想华莱，开展深度考察交流活动。</font>

我们一起来看一下理想华莱的硬广告。不知道现在还有没有人在继续交2万8的加盟费，但是我注意到，早在去年12月，我那期节目发出几周之后，安徽祁门县的市场监督管理局已经发出了官方警告。请静静帮我读一下。

<font color = "indigo">近期，多地发生以黑茶名义从事传销活动的事件，通过夸大虚假宣传黑茶的治疗保健效果，引诱参与者发展人员骗取钱财。不管传销组织如何变换手法、伪装自己，只要同时具备以下三点，就可以断定涉嫌传销：一是交纳或变相交纳入门费；二是直接或间接发展下线；三是上线从直接或间接发展的下线的销售业绩中计提报酬。</font>

我非常理解祁门县的政府机关为什么会急着揭露安化黑茶传销问题，因为祁门县自己就是茶叶大县，祁门红茶在国内和国际上都有不错的商誉。50年代一五计划期间，苏联几乎是单方面向中国输出资源，祁门红茶是中国极少数能够返销苏联、换紧缺工业物资的中国产品。为此苏联还向中国派出了专家团，指导农民按照苏联的需求制造标准化产品。2025年祁门县的GDP总量是110亿，其中差不多一半和茶产业相关，所以祁门县最怕其他茶企业搞传销，把市场玩崩了。无论中央机构管不管安化的理想华莱，祁门县都必须关注自己的生存问题。这也说明，让所有的利益集团畅所欲言，国家只用法律约束，客观上就是能够产生舆论监督效果。

942期节目的标题是《尿毒症工厂 劳动才有尊严》，介绍了广州郊区一家民营透析中心开设的服装厂，让病人从事力所能及的劳动，缓解整个家庭的致贫压力。上周4月23日，澎湃新闻有一篇后续特稿《一个肾友工厂的生存实验》，请静静读一段报道。

<font color = "indigo">一个尴尬的现状是：透析中心是赚钱的，但制衣厂是亏本的。谢强称，制衣厂成立以来已经亏损了400万元，最多的时候一个月亏了30多万元。最初制衣厂有其他股东，但搞了几个月，股东见持续亏本就直接退出了。谢强表示，制衣厂和工人不是劳动关系，更像承包日结模式。制衣厂之所以亏本：一是工人多是患者，上班时间无法保证，产能偏低；二是他们包吃包住，隐形成本比较高；三是多数订单都是发往内地的，给的价格比较低，而他们在广州是按广州的工价成本在运营，利润很低。谢强直言，他最初办制衣厂是为了稳定客源，更多是商业行为，后面见尿毒症患者这么困难、这么需要工作，他确实想帮他们，但若一直亏本严重，他也只能放弃。虽然已经有了非常大的关注和支持，但还是有很大的困难。谢强称，目前这一场平均每月亏10万元，但好的趋势是，有了外界的帮助和支持，整体亏损是在逐步下降的。</font>

有人资助亏损的透析服装厂肯定是好事，但如果希望好事能长久一点，最优方案还是直接捐钱给病人。服装厂本身还是要市场化运行，否则企业和慈善混在一起容易账目不清，也容易导致企业失去竞争力。等到援助一断，连眼下的贡献都不能维持下去。

第1017期节目标题是《18层楼锁电梯 柳州逼社区自治》。当时我说，如果业委会或者社区没有执法权，不能强行征收物业费，不敢拍卖欠费的房子，早晚大多数小区都会变成贫民窟，尤其是高层住宅。4月16日，中国新闻周刊有一篇特稿《拒绝交物业费的业主，把物业逼走了》，请静静读一段。

<font color = "indigo">全国500强物企平均收缴率已经从2020年的93%跌至2025年的71%，连续4年下滑。而中国物业管理协会曾指出，物业费收缴率85%是行业公认的运营警戒线，达到这一比例才能覆盖基础运营成本。这意味着很多小区的物业经营实则是在盈亏线挣扎。物业服务行业虽然是充分竞争行业，但不必然意味着有退出就会有进入。西南某市的李丹购置一套次新房仅4个月后，就收到了物业发来的退场通知书。据他介绍，小区自2021年交付以来，业主欠物业费，平均收缴率仅34%。这其实是个烂摊子。物业服务不仅关乎居住体验，更影响房价水平，而用于做婚房的房子正在装修，卖掉不太现实。李丹发帖感慨，评论区里不少同病相怜的业主大倒苦水。物业离场后小区陷入失序，垃圾清运、乱停车都成为问题，电梯甚至停运，门禁也失效了。后续竞标没有物业公司愿意进来。</font>

一个社会里面如果没有人去扮演执行规则的坏人，大多数人很快就会丧失当老好人的资格。社会主义国家确实应该保证穷人的居住权，但是不应该保证每个人都能住单独的公寓房。国家可以给失去房子的穷人提供集体宿舍，保证能够住硬板床，吃上2000卡热量的饭菜。但是如果这个人占有价值几十万几百万的房产，还不肯交物业费，那把房子交出来也是公民的义务。只是义务必须对应权利，中国应该尽快鼓励普遍的社区自治，鼓励社区选举有工资的业主委员会行政机构。

第188期节目，我们介绍过江苏常州市金坛的盐穴储能项目。当时金坛区先是利用盐矿空间存储了天然气，验证了地下空间储气的可行性，然后尝试建造压缩空气电池。最近几天，新一批的压缩空气管道的方案已经公布，看来一期的效果不错。4月26日消息，河南省平顶山市建设了一个3万立方米的储气盐穴，准备储存150万立方米的氢气。也就是说，当地准备利用地下储存50倍大气压的氢气，当做一个超级电池，平衡风电和光电的波动。2025年，中国的发电量10.4万亿度，其中风电加上光伏只有2.3万亿，还不到四分之一。限制风电和光电发展的最重要条件，就是储存能量的规模。接下来几年，中国工程方面的创造能力很大一块会用在储能方面，我们会看到各种花样的超级电池。
