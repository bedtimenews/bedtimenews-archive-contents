# 

大家好，2026年6月2日星期二，欢迎收看1061期睡前消息。请静静介绍话题。

<font color = "indigo">最近有媒体统计了各省的一季度财政收支数据，发现已经公布数据的29个省市自治区里面，没有一个省级单位的财政自给率达到100%。督公，你怎么评价？</font>

31个省市自治区，有29个有数据，剩下的两个，一个是新疆，一个是青海。青海去年的财政自给率是16%，排名倒数第二。新疆去年的财政自给率是40%，夹在江西和河南之间，排名第18，都不可能在一个季度之内就翻盘超过100%。所以确实是所有的省级单位财政自给率这一次都低于100%。

另外顺便说一下，新疆去年的40%财政自给也不算是很实在的数据。因为新疆除了接受中央政府的转移支付之外，还大量的接受点对点扶贫，以及很多不记入财政的隐形援助，实际的财政自给率恐怕是和黑龙江和吉林差不多，在20%到30%之间，排名应该是倒数第5名左右。

但是31个省全部收支不平衡，并不是一个非常严重的事情，因为本来全年的数据就不平衡。从全年来看，2025年哪怕是排名最高的上海，自给率也只是85%。这是中国的税制和财政自给率的计算方法决定的。按分税制改革之后的财政分配方案，中央要拿走关税、车辆购置税和央企分配的利润，还要以消费税的名义去控制烟草红利。增值税和所得税中央要拿走一半或者一多半。地方完全能够自己控制的税种，除了土地相关税之外，就是一部分环境相关收入。这套方案注定了地方政府的收支很难平衡，必须要依靠中央的财政转移。

当然了，过去十几年地方上还可以卖土地赚钱。但是财政自给率的计算方法是一般财政收入除以一般的财政支出，卖地收入是另算的，所以财政自给率普遍低于一，并不奇怪。

这次媒体讨论的是一季度数据。按照惯例来说，大多数省市的一季度数据就是要比全年更差，因为上一年的汇算清缴未必完成，但是重大的基建项目往往已经开始花钱了，而且花钱比例往往会超过全年的四分之一。所以如果去年全年的财政自给率都没有一个省市超过百分之百，那就没有必要奇怪为什么今年一季度的数据都低于百分之百。

如果一定要在今年一季度的数据列表找一些异常，我认为有三组数据值得关注：上海、天津、湖南与江西。

先说上海。媒体抱怨一季度所有省级单位的自给率低于百分之百，几乎就等于点名上海了。因为过去几年，如果不考虑深圳这个半独立结算的准省级单位，能够在一季度做到自给率超过百分之百的地方，就只有上海这个独苗。搜狐统计了2017年以来的十年数据，居然只有受疫情冲击最严重的2020年和今年，上海的一季度自给率低于一。

这首先是因为上海全年的基础数据就比较高，只需要一点点中央转移支付就能平衡。其次是因为上海的建设投入一般都比较平稳，如果搞大项目不会靠年初的新拨款才能开工。第三就是上海城市历史比较长，大多数支出都是民生项目，一季度往往还在重新统计受益人数，二季度才开始大规模拨款花钱。所以在其他省市一季度数据偏低的时候，上海的一季度数据要相对好看，能够在接近百分之百的全年数据基础上，再提升一点超过百分之百。

至于说为什么今年的一季度，上海的财政自给率忽然下降，主要的原因不是上海收钱少了，而是花钱多了。去年上海一季度收钱2552亿，今年是2605亿，区别不大。去年一季度花钱2408亿，今年是2897亿，正好增加了百分之二十，直接消灭了全国唯一的一季度自给率超过百分之百的案例。

在全国其他地区的房地产经济基本停滞的时代，上海的市区搞了新一轮的城市更新，成片的再拆老城区。同时上海的郊区还搞了地铁环线，嘉定、闵行这些地方也有新建的地铁线路，甚至上海还有南北贯穿市区修建地铁19号线，在陆家嘴的繁华地段拆小区，提供地铁用地。所以上海出现了罕见的一季度基建拨款增加。

另外，现在上海担心上汽集团这些老国企会掉队，第二产业衰落，失去工业城市的身份，2026年上海的AI和生物科技方面增加了政府投资。从财政局的数据来看，上海绝大多数预算项目都和去年持平，唯一的两位数增长项目是科技支出，达到了17%。这两个数据结合，说明其他地区在土地财政退潮之后，都在建设投资方面采取了谨慎状态，上海是唯一还敢搞大都市建设的省级单位。

然后我们说第二个异常地区天津。2025年全年天津财政自给率是66%，全国排名第6，不算差了，但是前面被上海北京这两个直辖市甩开了，后面和山东这种广域省拉不开明显的差距。到了2026年第一季度，天津的自给率居然达到了89%，和上海打平，明显超出了北京。

从最直观的数据来看，天津今年一季度最大的变化就是不敢花钱了。去年全年一般公共预算是3360亿，平均到每个季度是840亿。今年一季度正是花钱的时候，支出只有718亿，财政自给率自然就上去了。

暂时放下财政数据，我们看经济规模。这张表显示，上海一季度花钱是天津的四倍多一点。同时上海的GDP5.67万亿，天津是1.85万亿，几乎是天津的三倍。上海以天津的三倍经济总量，花了四倍的财政开支，听起来似乎差距也不算明显。但是在上海和天津这种历史很长的城市，地方政府的开支大项都是教育、社区、社保这些很难调整的项目，三倍到四倍的差距已经很惊人了。天津市政府压缩预算的决心，看来不是一般的大。

2024年底，天津公开承认的政府债务余额是1.34万亿。到了2025年底，就变成了1.51万亿，增加了1700亿。当然实际增加的债务总量可能没有这么多，其中一部分可能是隐形债务转过来的。所以下一个问题是，天津还有多少隐形政府债务？答案是不知道。

去年天津的预算报告，对于隐形债务的说法是：非标高息隐形债务全部出清，有息隐形债务平均利率较上年降低一个百分点。到了今年的报告，说法改成了多渠道稳妥化解存量隐形债务，坚决遏制新增隐形债务。中央一再要求隐形债务公开化，但是天津还有一串的定义，就是不给总量的数据。

就在过去几个月，天津静海区的城投平台连续发行短期债券，用途是偿还短期债务。东丽区的城投平台子公司因为欠工程款，已经是被执行人了。我相信天津肯定在努力筹集资金，保证这些国资平台的运行，至少要把利息还上。

过去几年如果财政没钱，还债的主要方式就是卖地。从新闻看，天津最近的土地拍卖，往往就是本地的国企接近于底价拿下，基本上算是左手倒右手。比如说5月27日，静海区的住宅用地是天津轨交集团拿下；宝坻区的工业用地，本地国企用每平方米375元的低价买入。哪怕不考虑这些交易等于左手交右手，天津的总体土地拍卖规模也在下降。

根据天津财政局上周的数据，今年1到4月，全市政府性基金预算收入101.5亿元，同比下降了24.1%；全市政府性基金预算支出265.4亿元，同比增长4.4%。这里的括号特别标明，新增专项债收入安排的支出138.6亿元。砍掉一切能砍的支出，硬是把天津的一季度财政自给率砍到了全国第三，和上海基本持平。

这里我还要强调一个经常被人忽视的数据，就是过去十几年天津有一笔额外的资源红利。2025年，中国的原油总产量2.15亿吨，其中排名第二的省份是新疆，这完全可以理解，因为新疆是中国面积最大的省份，也是更靠近亚洲中部的产油带省份。第三名是黑龙江，这也可以理解，因为大庆油田在黑龙江。但是在新疆和黑龙江的前面，天津以4000万吨的产量排名第一，而且有明显的优势。

天津现在石油年产量4091万吨，除以天津常住人口1364万，平均每人每年是三吨石油，毫无疑问是中国第一名，和俄罗斯的人均石油产量已经差不多了。现在俄罗斯最核心的产业就是石油和天然气，在发动大规模战争的同时，靠石油把人均GDP拉到了1.76万美元。天津的石油红利，按照相对比例来算，应该是和俄罗斯差不多。

天津石油产量高，首先和本地大港油田有关系。中国一共这四个直辖市，北京上海完全没有石油，重庆只有页岩油，靠国家补贴有微不足道的产量。而天津郊区有一个全国数得着的大港油田，每年产量是三四百万吨。除此之外，天津四千万吨的石油产量完全来自渤海油田。渤海油田在天津管理的海域之内几乎没有采油平台，绝大多数采油区要依托河北、山东和辽宁的岸上设备生产。但是因为中海油的管理总部是在天津，几千万吨的产量全部都算天津的。在税务和财政方面，渤海油田也是一个天津企业，它的税务汇缴地点是天津滨海新区的天津税务局第四分局。按照国家规定，油气资源税完全是中央拿走，但是企业所得税、企业增值税、员工的个人所得税，天津可以拿到接近一半。估算下来，天津每年直接拿到了差不多200亿的税收。

此外，因为渤海油田的总部在天津，这4000万吨石油的加工处理和上下游产业，也有相当一部分要放在天津。比如说天津滨海新区，要知道海上石油平台的组件，天津无缝钢管厂要给渤海油田供应管道；中石化还要在天津设一个大型炼油厂，这又提供了十几万个高薪岗位，和100亿左右的地方财政收入。早在2006年，渤海油田的年产量就已经超过了1500万吨。天津的石油红利已经吃了20多年。

回到财政自给率的话题。大多数省份的自给率和GDP排名差不多。比如说现在人均GDP最低的省份是甘肃和黑龙江，这两个省的财政自给率也排的倒数第几名，只比青藏高原上的西藏和青海略好一点。但是在排行榜的中游，有一个明显的反差，就是湖南和江西的对比。

看人均GDP数据，湖南是8.46万，江西是8万整，湖南有明显的优势。但是去年的全年财政自给率，江西41.46%，湖南是36.80%，江西反超了湖南。这说明江西GDP的质量更高，政府的实力也更强。这其中的原因我估测，有一半原因是因为江西的资源比较适合搞新能源汽车，锂矿带动的汽车产业链拉高了税收。另外一半原因，应该是长三角的经济辐射能力更强，压倒了珠三角的辐射。

过去一百年，因为京广铁路一响，湖南的出海通道在广东方向，依附于珠三角。而江西地理上靠近长三角，还有浙赣铁路和长江这两条便利通道向东，所以经济上依附于长三角和上海。从产业分布来看，珠三角虽然整体实力强，但是对于广东本省山区的辐射都很一般。而长三角已经跨省，把半个安徽拉进了自己的经济圈。所以江西靠拢长三角，在经济质量方面反超了湖南。

还是说财政自给率问题。上海、天津，再加上江西湖南的反差，这三组相对异常数据反映了一条共同规律，就是中国未来的经济几乎完全看大都市圈的发展水平。

以上海为中心的大都市圈建设，现在看来是成功的。直到2026年，上海还敢大规模搞旧城改造，搞地铁建设，补贴先进产业，所以财政自给率常年能在85%以上。而京津都市圈过去时间发展明显不如长三角或者珠三角，别说是天津，就是北京主城区，大片的老城区也几乎没有改造计划。天津前些年的折腾比较大，现在就算赤裸裸的卖户口红利，也没有多少人来接房地产的盘。在沉重的债务压力下，天津只能是想方设法避免违约，其他一切需求都放在后面。

湖南和江西的对比背后还有一条暗线，就是江西从来没有指望过南昌或者九江能够成为全国性中心城市，比较客观的选择了向长三角靠拢。而湖南有长株潭都市圈规划，短期的目标是争夺武汉的中部核心地位，长期目标甚至有辐射全国的雄心壮志。现在回头看，别说争夺区域中心地位，长沙连整合株洲和湘潭都没有做到。今年有媒体回顾停运的高铁站，首先就提到了长株潭城际铁路的九郎山站，停运之前每天客流量不到十人。从地图上看，九郎山很接近长沙和株洲、湘潭的中心位置，连这里都不能提供城际铁路的客流，长株潭一体化的伟大计划应该是已经暂停了。

对于一个城市或者一个省来说，现在看来最好的发展结果是成为一个都市圈的中心，这对应了上海或者深圳，在现行的分税制下也能勉强财政自给。其次是做理性决策，融入某个都市圈，这对应了江西，从比较低的起点出发，实现了较高的财政自给率。相对较差的结果，那就是天津或者是湖南长沙，借债搞基建，企图营造一个有全国影响力的都市圈，并成为中心城市，失败之后不仅没有拿到财政增量，还要承担巨大的债务压力，需要国家越来越多的财政支持。今年五月份的新闻，在央企信达公司支持之下，湖南要创建一个债务清欠示范区，首先选了株洲当样板。请静静读一段《金融时报》的报道。

<font color = "indigo">*落子湖南，助力建设债务清欠示范区。中国信达积极响应湖南省政府部署，首创应收端存量资产盘活加应付端专项信用工具双轮驱动模式，累计投资超11亿元，盘活地方国企长账龄应收账款及不良债权，并设立专项信托计划，通过共管账户精准督促还款清欠。相关实践已成功落地于全省唯一试点城市株洲，有效阻断债务风险传导，帮扶产业链中小企业，为打造全国连环债务清欠示范区提供了市场化、法治化解决方案。*</font>

具体的都市圈发展问题，欢迎各位回顾[第956期](/main/901-1000/956)和[第957期](/main/901-1000/957)节目我对陆铭教授的采访。这里我还是分析财政自给率。这期节目一开始就说了，因为现行税制倾向由中央财政，所有的省级财政自给率都低于100%，从会计角度来说不是非常严重的问题，或者说这可能就是中央预期的结果。但从管理学角度来说，既然中央补贴已经常态化，就说明有一部分应该由中央政府来安排、也是中央政府来花钱的事情，实际上由地方政府来执行，凭空增加了监督成本。

除了借债、卖地和少量的罚款之外，地方政府弥补亏空的唯一方式就是中央转移支付。2025年和2026年，中央转移支付都是10.4万亿左右，估算的时候可以粗略算到10万亿。

这其中第一部分是专项转移支付，总量是9000多亿，粗略算它1万亿，范围包括控制传染病、治理污染、循环园区建设，都是专款专用，地方政府没有资格去改变用途。

第二部分是4万亿上下的共同财政事权转移支付，主要用途是纪律检查、义务教育、文物保护、基本养老金。理论上来说，这4万亿也是专款专用，但是地方政府只要能够满足法定的工作指标，至少可以暂时挪用一部分，弥补其他方面的财政压力。

第三部分是5、6万亿的一般性转移支付，其中最大的项目是均衡性支付，其次是税收返还，这是真正的地方财政自由资金，可以按照地方政府的规划，拿去补缺口、还债或者是搞建设项目。

由此看来，10万亿的转移支付，专项支付和共同财政事权部分起码占一半，地方政府在这部分只是帮中央政府去雇人干活。或者说，这部分工作的人事权在地方政府，财政权在中央政府，两种权责的割裂性反映在会计账簿上，就是地方政府的财政自给率永远到不了百分之百。

稍微有一点社会阅历就知道，花钱让不同的单位去干活，最终产品肯定不一样。别的不说，现在推广自动驾驶，有一个严重的障碍，就是中国不同省份、不同城市的红绿灯和城区的交通标志，都有明显的差异。比如说天津市，一度所有的红绿灯都有进度条，不用倒计时。后来才知道，这是公安局长武长顺设计的。现在武长顺判死缓也快十年了，还有红绿灯没有换回国标。

至于说教育服务、养老金政策，各地更是千差万别。过去中央政府似乎也不是很在乎各地的公共服务有差别，只要能稳定就行。但是就在十天之前，5月22日，国务院印发了《关于推行常住地提供基本公共服务的实施意见》，听名字就能知道这个文件的主要目的。请静静帮我读一下其中的财政安排。

<font color = "indigo">*9.加强财政转移支付保障。根据基本公共服务覆盖常住人口进度，完善相关转移支付考虑常住人口因素进行分配的做法。对符合条件的、基本公共服务领域共同财政事权转移支付项目，探索根据保障标准、常住人口规模、支出责任分担比例等因素进行分配，鼓励省级财政转移支付加强对人口流入地的财力支持。*</font>

这里有两层意思。首先是根据常住人口数据给转移支付，户籍人口数据要永久作废。其次是按照责任给钱，给了钱就要保证服务一致。说实话，我不太相信真正做到服务一致，最起码在高考和中小学教育经费方面，我不太相信北京天津会这么轻松的放弃自己的特权。其中一部分原因，就是地方政府自己去负责人事安排，肯定要按照自己的稳定逻辑去花中央的经费。

所以我的期待是，既然所有的地方政府都要靠中央转移支付才能提供基本服务，那还不如继续扩大中央的财政权力，不要搞什么转移支付了，直接把中央列出来的基本服务都转为中央的直属机构，地方政府只去管有地方特色的部分。比如说中小学，如果真希望有均等服务，那就全体转为教育部的编制，地方政府既不需要收这部分的税，也不用对基本服务负责任。如果地方政府财力富裕，愿意提供额外的文化服务，那可以在小学对面另外建自己的青少年活动中心。没钱建，那也不影响中央政府的政绩考核。

在这种制度下，中央收钱中央花，让国民待遇可以变成一种看得见摸得着的东西，不能遮掩，也不能推卸。同时除了少数边疆，大多数地方政府也能在较低的水平上实现财政平衡，免得人事和财政分离。

从全世界发达国家来看，中国的中央政府收入和责任都是偏低的。2025财政年度，美国中央政府财政收入5.3万亿美元，地方的州和基层政府财政收入加起来是3.96万亿美元，中央政府的收入是地方政府的134%。而中国中央政府的财政收入9.4万亿，地方不算转移支付，本地的财政收入之和是12.2万亿，中央政府收入只占了地方的77%。考虑到地方政府还有卖地收入和隐性的发债收入，中央财政比例就更低了。

更进一步说，前面提到过，中央转移支付已经稳定到10万亿以上，而中央自己收自己花的财政收入只有9.4万亿。就算中央还可以印钱搞赤字财政，也是地方政府花钱要多得多。

所以到了2026年，建国77年了，基本公共服务还是要和户口挂钩。现在中文提到国民待遇这个概念的时候，主要是用的外交领域，用来形容外国人和外国企业得到的政策优惠，很少会用来衡量内部的基本服务是否一致。从前面的分析来看，这和转移支付的使用方式是有关联的。

所以31个省市都不能财政平衡，财务上也许不是问题，社会服务方面肯定有问题。中央政府如果真的希望落实基本公共服务，最好的办法就是自己收钱自己花，做一个名副其实的大政府。
