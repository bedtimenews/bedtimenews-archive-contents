大家好，2026年6月26日星期五，欢迎收看1070期睡前消息。请静静介绍话题。

<font color = "indigo">6月6日，上海海洋大学宣布，全球首台智能鱿鱼钓机开始海上实验。按照官方说法，新装备可以实时捕捉鱿鱼咬钩脱钩的动态信号，同时复刻了人工手钓的拉线抖动，通过智能算法模拟钓捕节奏，新装备能大幅提升钓捕效率。督工，这类机器会不会制造大规模的失业？</font>

不会，因为鱿鱼产业的机械化水平已经很高了，新的机器人只是能够在特定场合替代最后的钓鱼工人。鱿鱼一般分成两种。中国的近海一般都是枪乌贼，体型普遍比较小，单只在二两左右，肉质比较少，就算是品相完美，也要归入廉价食材，卖不上价。我们一般吃的炒鱿鱼、烧烤小鱿鱼，就是用这种枪乌贼。所以在中国近海，钓鱿鱼基本用不上高价值的人力，直接用底拖网把所有的海底生物都拉上来，就算鱿鱼的形状破损，也可以拿去做罐头或者饲料，收入差不多。

要想在鱿鱼产业赚更多的钱，那就必须捕捞大洋鱿鱼，单只可以达到上百公斤，肉质比较厚，出肉率也高。我们在超市买的鱿鱼丝、街头小吃的轰炸大鱿鱼，以及下火锅用的厚鱿鱼片，全都是大洋鱿鱼。大洋鱿鱼的产地一般距离中国很远，比如说阿根廷外海的西南大西洋，秘鲁外海的东南太平洋。每年一月份开始，南半球进入夏天，鱿鱼资源多，中国渔船就会在这里集中作业，主要是依靠机器捕捞。一般来说，远洋鱿钓船会先打出几百盏大功率的LED灯，吸引有趋光性的浮游生物和杂鱼。鱿鱼作为掠食动物，就会跟着这些食物从深海来到浅海。这个时候，船上的自动钓鱿机开始运转，把挂了发光拟饵的钓线丢到海里，模仿虾和鱼的走动方式，吸引鱿鱼抱上来挂住。机器判断是挂到了鱿鱼，最后把钓线拉上来，经过一个滚筒，鱿鱼因为重力原因会掉下来，顺着传送带掉进加工舱。

在鱿鱼资源比较丰富的区域，人类船员的作用首先是拆线。机械吊线可能会因为风浪缠到一起，大量的船员需要随时待命，在机器后面解线换钩。人类第二个作用是鱿鱼粗加工。鱿鱼一旦离开水，就会很快死亡和腐烂，时间以分钟计算。鱿鱼是软体动物，身体光滑，大小不同，还做不到机械手处理。所以鱿鱼被吊上船之后，工人就要立刻粗加工，按照大小分级，挖掉内脏，摆盘翻进冷冻库。钓鱿鱼的船员一边管机器，一边手工还要钓鱿鱼。西南大西洋和东南太平洋的鱿鱼多，靠机器就能捕捞，已经吸引了大量的中国渔船，改变了鱿鱼的产业格局。2019年，中国官方宣布，中国远洋鱿鱼产量是52万吨，连续9年达到世界第一，占全世界的鱿鱼产量20%，也创造了历史记录。第二年情况就不一样了。请静静帮我读一段2020年的报道。

<font color = "indigo">2019年，鱿鱼就没有出。刘国诚说，去年下水的新船差不多100艘就赔死了，2019年被称作绝产。据舟山日报对舟山市远洋渔业协会的采访，2007年到2011年，西南大西洋的中国钓鱿船单产达2000吨以上，而近年来单产仅200到400吨，2019年只有50吨。</font>

深海鱿鱼的平均寿命只有一年。每年7到11月，是西南大西洋和东南太平洋的鱿鱼产卵期。如果这三个月还不收手，很容易就把怀孕的母鱿鱼和小鱿鱼一起打上来，第二年就捞不到了。所以2018年中国鱿鱼产量创造纪录，2019年就开始亏钱了。为了保护远洋渔业发展，农业农村部颁布规定，从2021年开始，中国籍船只必须在核心产区休渔，主产区不能钓。中国渔船就开始转战西北太平洋的公海，中国、日本、俄罗斯中间这片海域。北太平洋的鱿鱼产量不到另外两个产区的三分之一，鱿鱼的密度低，机械流水作业的效果就不好。

前面提到鱿鱼要卖高价，其中一个关键因素就是品相，尽量不要破损。所以钓鱿鱼用的鱼钩，一般也不会安装倒刺，更倾向于使用伞钩，吸引鱿鱼缠绕上去。作为一种无脊椎生物，鱿鱼和乌贼都算是智力很高的。如果鱼钩的抖动频率不自然，鱿鱼就不会上钩。尤其是北太平洋，鱿鱼少，食物竞争没有这么激烈，鱿鱼就先用触手进行试探，确定鱼钩安全再缠绕上来。如果使用机器，就很难判断鱿鱼是不是在试探，容易脱钩。所以渔船到了北太平洋，就要人工下钩，模拟抖动，再用人工的经验去判断鱿鱼是不是真的上钩。鱿鱼资源越少，人工钓鱼的效果就越明显，产量甚至可以达到机器的5倍。北太平洋这片公海，就是人工钓鱿鱼的最大需求。

从20世纪90年代开始，上海海洋大学就开始研究适合北太平洋的鱿鱼机。现在海洋大学用人工智能去研发新一代的鱿鱼机，也是到北太平洋去做海上实验。

<font color = "indigo">北太平洋的钓鱼工人现在收入怎么样？</font>

不算好，纯粹是赚个辛苦钱。远洋渔业整体上就不算赚钱行业，利润大头都来自政府补贴。2016年，世界各个渔业大国花了42亿美元去补贴渔船，几乎等于行业利润两倍。对比世界上的同行，中国的渔船对于政府补贴依赖程度更高。有媒体统计过，如果没有补贴，中国每艘渔船利润下限是亏损500万美元，上限也就是刚刚盈利；算上补贴，一艘船最多也赚不到500万。和其他类型的渔船相比，鱿渔船的利润还要再降一个层次。中国的远航渔船主要是捕捞三种鱼：金枪鱼、鱿鱼，以及西非海岸各种鱼类，包括沙丁鱼、鲹鱼。金枪鱼作为高档的海鲜，价格比较高，毛利率可以达到22%。西非海岸这些其他的鱼类，虽然毛利率不高，但是产量高。鱿鱼船需要买机器，也要配人工，价格还赶不上金枪鱼，那毛利率只有8%。

大企业肯定会优先选择高利润行业。行业统计数据显示，中国一半的金枪鱼产量都来自国企，集中在20艘国企大船，其他捞金枪鱼的民营企业，也基本上都是上市公司。到了鱿鱼行业，情况反过来，超过68%都是民营企业，上市公司只有16%，小渔业公司是主力。鱿鱼船不赚钱，那就开不出高工资。有调查公司对比了国际渔船和中国渔船的工资水平：国际渔船上，船员的平均工资最少是2300美元，也就是人民币15000；同期的中国渔业公司披露数据，最低是6000块，高一点也就7600块左右。刚才提到这些中国船员的工资数据，基本上来自上市公司。鱿渔船主要是中小型民企运营，实际情况可能更糟糕。请静静帮我读一段行业研报。

<font color = "indigo">大量中国渔船普通船员的收入在300美元左右。如果没有廉价外包劳动力承担大部分甲板工作，渔船的盈利能力将大幅下降，特别是金枪鱼延绳钓和鱿钓。如果企业不借助廉价外包劳动力，而是按国内行业标准向船员支付工资，就无法盈利。</font>

除了工资低，渔船还要采取各种灰色手段降低成本。请静静读一段2025年澎湃新闻的报道。

<font color = "indigo">在远洋捕捞渔船上，大部分空间用于捕鱼作业和储存渔货，船员们的日常生活区域狭小。阿新的船上有十多个房间，是六人一间的上下铺，床长两米宽一米，卧室的过道里刚好能容纳下并肩而站的两个人，可供走路的空间只有五六平方米，四个人要借位才能顺利上床。宿舍里没有浴室，也没有独立卫生间，船员们只能在甲板上露天冲水。但水在海上很宝贵，他们有时用海水冲澡。根据餐标，二十几个成年男子，一餐只能分食两三斤肉，平均下来一人能分到一点肉末。远洋渔船上岗位固定，没有替补人员，不管是谁，除非生大病实在无法动弹，碰上小病小痛只能带病工作。船员们一边操纵机器捕鱼，一边手工钓鱼，重复这动作直到次日早上六点。钓上来的鱼要立刻分类清理，然后送进冷冻舱。在零下50多摄氏度的舱内工作，要防止冻伤，而且冰冻后的大鱼就像石头，一不小心就会砸伤手脚。关于船上的冲突，起因经过是混乱的。船员都太孤单，在海上待久了，性格会慢慢有问题。有一次阿环去其他宿舍聊天，有一个喝醉酒的船员无端打了他，两人扭打起来。打人船员无法忍受工作的高压和低薪，闹着要回家。有船员想家想到精神不正常，甚至出现幻觉，因此会做出一些过激行为。一些杀人事件在船员间流传。李星经常听船员们说，长期孤单的航行，再加上繁重的劳动，船员很容易产生幻觉，老感觉有人要害他。</font>

新闻里面提到的杀人事件，并不是传闻。绝大多数中国人第一次注意到远洋渔船的工作环境，应该就是鲁荣渔2682号事件。十几名渔业工人觉得收入太低，也被管理层虐待，劫船找公司要说法，最后导致22人死亡。这个鲁荣渔2682号就是一艘鱿鱼船，按计划绕到东南太平洋去钓鱿鱼。惨案发生到现在已经过了将近15年，情况有没有更好一点呢？请静静帮我再读一段2025年的报道。

<font color = "indigo">2025年3月11日，威海海警局接报警，在印度洋海域作业的鲁荣远渔370船发生一起海上杀人事件，被害人被杀害并抛尸到海里。嫌犯名叫林某兵，为该船二副，此前曾数次跟随遇害船长出海。多项证据显示，案发前已有征兆：3月8日前后，林某兵表达过离职返港回国的想法；案发前一天，林某兵曾持刀独自站在甲板之上，之后他一度跳海自杀，被楚一军联合船员救下；次日一早，他关闭监控，开始行凶。</font>

按照后续新闻，凶手跟被害人既是朋友，也是老乡。凶手一开始是想自杀，后来转头决定杀害船长，导火索可能是下面这段话。楚一军说，出发到海洋上就要一个月，真正干活不到两个月，让林某兵把剩下两个月的活干完，这样才不会被扣工资。船员船长都是和船公司签订的合同，出海20多人，每次出海成本都比较高，所以合同对于船员的工作时间都有要求，一般要装满渔货才能返航。

这两起案件有共性。2011年的案件，反对者一开始杀了6名反对者，动机还比较清楚；等到反对者控制了船只，暴力逐渐失控，演变成高烈度的内讧，部分船员一开始也没有杀人，为了交投名状，只能入伙，又造成16人死亡。2025年的案件，凶手从想自杀变成杀掉船长，也没有跟船长发生争吵。一般来说，凶杀案或者是因为矛盾，或者因为利益，渔船发生的暴力事件，更像是随机杀人，只能是判断是长期处在高压力环境，导致船员的精神状态出了问题。

既然工作环境这么恶劣，工资还很低，为什么还有人愿意上船钓鱿鱼呢？睡前消息1043期分析猪周期问题的时候，当时我说，养猪企业招人的时候一般不说实话，新员工不知道真实的工作环境，入职之后容易产生心理问题。养猪企业只是对环境不说实话，工资还算可以，而且按时发放。很多渔船招人，纯粹就属于诈骗了。像舟山、大连这些渔业公司集中的地方，执法部门一个主要任务，就是打击船员招工骗局。检察日报去年有一篇专题报道，标题叫《他们掉入了连环局》。请静静帮我读一段。

<font color = "indigo">博主表示，自己在舟山做船员招聘中介，认识很多公司，船员的年薪在10万元左右，干满两年就可以拿到将近20万元。很快，李某便来到舟山，开启了为期一周的船员培训。第一天，李某便被中介要求缴纳了近2000元的住宿费，后来中介又预扣了5000元培训费。中介为他联系到了一家渔业公司的远洋渔船，负责钓鱿鱼的工作。李某清楚，中途离开就意味着拿不到全部工资。根据上船前双方签订的合同，船员出海一年内中途回国的，会按照时长扣除相应工资。为此，他坚持干到了2023年11月。没想到，船东联系到的接驳船需要提前返航，他不得不随船回国。船东说，还差四天才满一年，所以不能拿全年工资，按合同只能拿到全年工资的30%。扣完工资，李某一年下来只拿到3万余元，除去培训费、船上生活费，最后到手仅有2万元。</font>

年薪10万左右，干满两年将近20万，对于绝大多数没有高学历的人来说，已经算是高薪了。在交了几千培训费之后，为了不亏本，很多人只能是忍着低薪长期干活。前面检察日报提到的渔业公司，只是在合同里面设了陷阱，通过各种手段去扣钱，这对比其他的同行，已经算是讲良心了。有些渔船可能是上去就下不来。我再分享一个环球网的报道：2017年8月，刘某租用了某号船出海捕鱼，并通过中介机构招聘郑刚、王军等人到船上工作。郑刚上船后，发现与承诺工作环境有天壤之别，提出辞职下船，但遭到刘某拒绝。郑刚拒绝劳动，被崔某等人殴打，关在船舱内。无奈，郑刚开始绝食，三天后郑刚陷入昏迷，刘某这才将郑刚送到岸上，到医院进行救治。2017年9月，王军开始到船上工作，因工作强度大、环境差，同样多次提出辞职下船，并同意支付违约金，但遭到刘某拒绝。9月4日，王军登上接货船，要求回到岸上，并持刀威胁，刘某三人持棍棒等将王军制服，然后对王军进行殴打，将王军拖回渔船，关在船舱内。同年9月6日，民警将王军从船上解救。

这个新闻里面提到的郑刚、王军，运气算好，船还没有走远。如果是远洋航线，船已经到了公海，工人除了老老实实干活，没有任何办法。除了被高工资骗上船的人，还有一部分船员背景比较复杂，在岸上找不到出路，只能是上船。就拿鲁荣渔2682号惨案来说，船上一共是33名船员，有的没有犯罪前科，厨师长没有前科，但是欠了债，指望钓鱿鱼来返本；杀掉船长的林某，有三次违法犯罪记录。渔船欢迎这些欠了债，甚至有前科的人，就是认为他们更驯服。

<font color = "indigo">睡前消息之前讨论采茶女工和蓝莓工人问题的时候，督工您提到，等到自动采茶机和蓝莓采茶机普及，这些岗位几乎就要被淘汰。现在中国已经研发了智能鱿鱼钓机，那鱿鱼船工人的岗位也会受到冲击吗？</font>

可能减少一些工作岗位，但是不会彻底消失。前面提到，在绝大多数工作场景，底拖网和现有的钓机都可以满足需要了，只有在北太平洋鱿鱼资源稀疏的区域，智能钓机才有使用场景。另外，清洗切割鱿鱼，也占到鱿鱼工人很大一部分工作量，目前没有合适的机器去取代。所以AI机器人如果真的能够取代一部分钓鱿鱼的工作，那也只是影响少数低薪而且危险的职位，对于全社会冲击不大。这里唯一值得注意的问题，是21世纪的中国居然还有那么多的壮劳力缺乏出路，会为了不到一万的工资上远洋渔船。

其他国家的船员工资往往更高，那为什么没有开发钓鱿鱼机器人？因为没有需求。全世界只有东亚的消费者喜欢吃完整的鲜鱿，品相越好价格越高。欧美处理鱿鱼，一般会去头去足，把肉切下来油炸做成鱿鱼圈。开头我们提到，中国在公海钓鱿鱼不用拖网，其中一个原因就是避免影响品相。欧美的消费者就不考虑品相，一般直接拖网捕捞了，根本用不上钓鱿机。所以欧美国家用AI技术改造渔业，重点还不是在于钓，而是在拖网识别系统，避免把珍稀鱼类和保护物种一起打捞上来。东亚国家考虑品相，日本1974年就开发出了机械钓机，现在全球的鱿鱼钓机有一半都是日本产品。但日本、韩国国内市场有限，没有进一步优化设备的动力。中国的市场是最近十几年爆发的，增量提供了最大的产业升级需求。前面提到，从2009年开始，中国每一年的鱿鱼产量都是世界第一，就这，还有进口其他国家的鱿鱼。所以哪怕只有北太平洋少数地方用得上，中国渔船也有可能会购买智能钓鱿鱼设备。

<font color = "indigo">三文鱼也算是深海鱼类，已经实现了人工繁殖。鱿鱼现在可以人工繁殖吗？</font>

如果鱿鱼的定义宽泛一点，可以说已经实现了人工繁殖。就在2024年，福建水产研究所已经实现了枪乌贼的人工繁殖。但是对于中国的鱿鱼行业来说，枪乌贼繁殖意义并不大。节目一开始就已经介绍了，枪乌贼在中国的近海分布很广，但是体型小、出肉少、卖不上价，所以中国鱿鱼产业要赚钱，主要还是靠深海鱿鱼。

任何一个物种要实现大规模的人工繁殖，必须具备一些基本条件。首先，生物的行为方式要有一定规律，小空间可以满足生存天性。三文鱼虽然需要不断的巡游，不能接受静止环境，但只要提供了循环水流，就会绕着圆形的水池不断转圈，所以中国已经开始尝试利用沿海的冷水区去养殖三文鱼。深海乌贼的习性是垂直洄游，白天为了躲避捕食者，会下潜到几百米甚至上千米的深海，晚上为了觅食再浮上来，人工水池就很难模拟深海鱿鱼需要的高压环境。

养殖第二个条件，是物种性格要稳定，不能随便应激。三文鱼有群居的本能，水体拥挤、同类多，它不仅不焦虑，反而感到安全。鱿鱼完全不同，如果空间狭小，就要开始相互攻击，甚至吃掉同类。如果光线和声音不对，鱿鱼还会马上喷水逃窜，撞到水池的边界死掉。最后一个养殖条件，就是不能挑食，投入产出比高。三文鱼可以吃饲料，鱿鱼就必须要吃高速移动的活鱼、活虾，深海鱿鱼每天要吃掉几公斤的活鱼。人工繁殖鱿鱼，如果没有合适的杂鱼供应，很有可能会亏本。所以一直到现在，大鱿鱼还是要靠捕捞。

前面提到，公海的远洋渔业一直能得到全世界各国政府的补贴，背后有两个灰色原因。首先是国际谈判惯例，公海渔业资源分配，往往是历史上的捕捞业绩会决定未来的配额，所以各国往往是捞鱼捞到快灭绝了才收手。其次，有的国家经常让远洋渔船为海军提供服务，以平民的身份去搜集信息，做战斗预警，所以也愿意平时给一些补贴。2022年之后，新的国际公约限制了恶性竞争，中国也开始控制给渔船的燃油补贴。同时，政府资金支持渔船的智能化改造，海洋大学用AI机器人来钓鱿鱼，一部分动力，就来自渔船智能化改造的国家补贴。
