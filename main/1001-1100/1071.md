大家好，2026年6月28日星期日，欢迎收看1071期睡前消息。我在道路通行权问题上逻辑是一贯的，就是公共交通工具之外的车辆，如果想得到合法的路权，就必须承担道路的运行成本。比如说998期节目的标题就是《电动车新规，车主得交钱修路》。之前的850期节目，总结了2024年几个高速公路重大伤亡事件的共性：都发生在经济比较差的地区。比如说人均GDP3.3万的广东大埔县，出现了死亡50多人的梅大高速塌方事件。虽然地方经济和道路养护经费并不是完全挂钩，但是比较穷的地方，往往也是地理条件差，汽车通行费也交的少，在整个高速公路体系内，这是烧钱的黑洞，不是赚钱的机器。一旦土地财政带来的无限建设经费，变成了需要考虑分配次序的有限资金，从概率来说，一定是这些穷地方先死人。在一个14亿人口的大国，概率论不会放过任何的侥幸心理。

这里我们回顾一下857节目的结论：国家补贴电动车产业没有问题，但是不能让公路系统来补贴。如果最后公路全面出问题，无论是燃油车还是电动车，谁也卖不出去。当然还有一种可能是，国家没有找到合适的方式去收电动车的税。15年前，国家用燃油税取代养路费，一个理由是燃油税和里程成正比，和汽车的重量也大致成正比，而在不超载的前提下，重量和里程和公路的积累损伤正相关。为了和燃油税对应，我们可能要强制每辆电动车都安装一个计量装置，计算用了多少电，然后用电量去交税。

最近几个星期，随着中东战争带来的油价波动，电动车是否应该承担道路养护成本的问题，成为大众讨论话题。我完全支持燃油车主提出自己的利益诉求，让电动车也承担一部分道路养护费用。但是最近几天，我发现正反两方面都在引用一个并不合理的公式。请静静帮我读一段36氪的近期评论。

<font color = "indigo">中国新能源车为什么越造越沉？新能源汽车过度增重，对道路、桥梁等公共基建造成的隐性破坏，也不容忽视。根据道路工程中的四次方原则，车辆对路面的破坏程度，与其轴重的四次方成正比。这意味着一辆整备质量2500公斤的汽车，对路面造成的损耗约为一辆1500公斤汽车的7.7倍。正如蔚来创始人、董事长兼CEO李斌在2026年4月的第四届中国科交会上所言：车重每增加20%，对路面的破坏率将达到原来的2.07倍，所以轻量化不光是对车的能耗、对车的安全有价值，对整个社会的效益和收益也是非常大的。2026年5月，李斌在接受采访时直言，如果中国3亿多辆车都变成重车，路就压没了。</font>

紧接着，一批跟风的自媒体，尤其是由AI写作的自媒体，开始宣传四次方破坏效果这个概念。也就是说，新能源车为了装电池，比燃油车重了几百公斤，看似相对比例不高，但是通过四次方规律放大，路面的损耗会产生几倍的差距，所以就必须让电动车多出钱。用四次方做关键词，用搜索引擎检索最近的媒体标题，我又发现了一大批跟风的半AI媒体。作为一个已经离职快20年的道路工程师，我确认一下：四次方公式确实存在，行业内的名字是轴载当量换算公式。这个公式的基本原理，也确实是测算公路力学性质的长期变化，用来判断汽车给沥青路面带来的损失。但是前面提到的所有人，无论是媒体作者，还是蔚来的老板李斌，都完全不理解这个公式的适用范围，把问题引到了错误方向。

首先，这个四次方公式并不适合所有的路面，只是沥青路面的经验公式。其次，公式处理的数据是轴载，一个双轮车轴承担的压力，而不是车的重量。当然，中国现在大多数路面材料确实是沥青，轴载这个数据也确实和车重相关，所以我就不纠结这种用词方面的错误了。最新一版规定了换算公式的国家标准，是2017年4月17日交通部发行的《公路沥青路面设计规范》。所谓的四次方，是换算指数b。可以看到，这个四次方还是指数的下限，如果综合考虑到道路的其他损伤，指数还要大幅度上升，甚至会增加到13次方。规范为了严谨，把公式写的就比较复杂。除了换算指数之外，其中最简单的一个数据是设计轴载，分母P。这个数据规范明确要求取成常数100千牛，也就是10万牛顿。至于说上面的分子，粗略理解为实际的轴载就行。按照g等于10估算，每一根轴上面有1万公斤，也就是10吨的质量，才能让括号里面的数据变成1。大家都知道指数增长的力量，如果轴上的重量明显超出10吨，对路面的损害就会飞速增长：超载100%，破坏至少是16倍；超载200%，破坏下限就是81倍。某些车超载在了300%以上，如果按照最夸张的13次方参数来计算，一辆车带来的疲劳破坏，等于路上所有正常行驶的车开好几年。这就是交警和路政要严厉惩罚超载的原因。

反过来说，那些轴载只有一两吨的车辆，也就是普通的家用轿车或者SUV，对于路面的冲击破坏，就是标准卡车轴载的几百分之一，正常的工程师便会直接忽略它们，减少工作量。所以请注意，公式上方有一句话：计算2类到11类车辆各种轴型。这个规范总共只讨论11种轴型，其中被要求忽略的第一类，包括了所有两轴四轮客车，根本就不去讨论具体的车重。别说李斌担心车重增加20%，就是增加一吨两吨，在规范看来都不值一提，完全没有列入统计数据的必要性。所以网上所有担心新能源轿车太重会破坏路面的内容，都是在胡说八道。

如果有人用所谓的四次方公式去测算通行费，一定会发现，无论油车还是电车，只要单轴重量小于5吨，都根本不需要缴费，最多是跟在卡车后面交几毛的零钱。但这并不是说家用轿车就不用承担沥青道路的建设成本了。因为除了对路面的冲击破坏，轿车还要占用路面空间，以及占用合理的车距空间。某些道路根本就不允许卡车通过，也一样得铺设足够的合格路面，所以哪怕是600多公斤的第一代五菱迷你，也有义务去分担道路建设经费。

此外，前面那个四次方公式，算的只是道路的受力指标方面的损害，并没有考虑天气带来的自然老化，以及沥青路面积水带来的破坏。这部分维护成本和重量无关，当然也需要卡车和所有的小型客车共同分担。当前中国高速公路的收费标准，基本的原则就是卡车按照重量收费，小客车也要为自己占用的空间和维护成本付费。如果要把燃油税包含的养路费用去分担给电动车，理论依据应该是让电动车主为自己的路面空间付费，而不是为整辆车的重量付费。

空间包括了纵向车距和横向安全距离。在纵向车距方面，电车和油车的区别不大，但是中国道路，尤其是市政设施的横向宽度一向比较紧张。考虑到旧城改造的压力，极限情况下，车道宽度会采取3米甚至2.8米的下限，普通停车位宽度更是只有2.4米左右。现在的电车，为了多装电池增加荷载，最大的问题是车越造越宽了，压缩了横向空间，明显增加了事故隐患。如果有人想指责电车制造了额外的交通压力，首先应该关心是车的宽度，而不是重量。

以上所有的讨论，有一个基本假设，就是普通公路上跑的电动车基本上都是家用小客车，长途卡车基本上都烧油。卡车制造了大多数的路面破坏，通过燃油税去承担大多数路面修复成本，那也是理所应当。但是这个假设马上就要失效了。5月29日，交通部、国家发改委、工信部、公安部联合印发一份文件《推动新能源重卡规模化应用实施方案》。请静静来读一段。

<font color = "indigo">加力提振市场消费，继续实施老旧营运货车报废更新活动，优先支持更新为新能源重卡，鼓励地方使用经济、技术等手段，引导市场主体购买使用新能源重卡。到2030年新能源重卡渗透率达到40%，保有量突破160万辆，占比达到20%左右。京津冀、汾渭平原等地区固定线路短倒运输电动化比例超过80%，结合高速公路网建设电动重卡补能设施，打造零碳公路运输通道，支持并引导建设重卡充换电站3000个左右。</font>

如果电动卡车的比例将来提高到不可忽视的地步，用燃油税来支付的养路费便会快速下降，交通部门不仅没有钱提供更多的路面空间，连现有路面的修复费用都会有缺口。所以电动车分摊养路费问题，必须尽快提上日程了。这个正确的结果，并不需要编造什么四次方规律来支持。

前面我提到了2024年52人死亡的广东梅大高速塌方事故。高速公路在凌晨2点无声无息的出现一条大沟，前面的车掉进去，后面的车完全不知道，继续跟着往下冲，连续掉了23辆。如果不是有人冒险在塌方前面拦车，死亡人数可能会上升到100。当时我在放暑假，节目没有立刻做出评论。我对同事说，以后土地财政退潮，山区的车流量进一步下降，养护经费紧张，类似的问题会越来越多。请静静帮我读一下后来的灾害评估报告。

<font color = "indigo">重建设、轻管养，日常隐患排查治理流于形式。调查发现，大潮公司仅有两名养护管理员负责涉灾路段养护，其中一名养护管理员2024年1月1日起事实上脱离岗位，养护人员数量和专业能力都远远达不到要求。至2024年5月1日前，大潮公司和陆路通公司仅完成约50%边坡排查。特别是2024年以来，大潮公司的养护人员从未检查事发的三级边坡，远远达不到每周对涉灾路段所有边坡全覆盖排查的要求。陆路通公司作为日常养护单位，不仅安排无资质人员从事日常养护工作，且实际进行日常养护的人数与合同约定相比严重缩水。在实际工作中，拍照及完成检查、以外包施工队的工作照片作为日常巡查证明等问题突出。涉灾路段日常管养和边坡隐患排查形式主义问题严重。</font>

当时我还说，最有效的应对方案，不是砸钱避免每一个路基的塌陷事故，而是在路基里面要埋上光纤，有塌陷就全线发警报，同时把信息传递到主流的导航软件。这样就算刚好路过的车掉进去，后面的车也能得到预警。请静静再帮我读一下今年才发布的灾害整改措施落实情况。

<font color = "indigo">加快提升公路设施安全风险监测预警能力。全省公路结构监测已覆盖1878处边坡、495座桥梁、50座隧道。会同省公安厅、省交通集团，在乐广高速京珠北段、梅大高速茶阳段等开展高速公路重大灾害监测预警及管控试点，建设完成221处灾害监测预警系统。省交通集团成立基础设施监测中心，搭建集数据分析处理、预警信息自动送达为一体的基础设施监测平台，设置专业力量24小时值班值守。</font>

在路基里面埋一根光纤，信号断了就认定是路基有异常，马上发出预警，这是最省钱的控制灾害规模的方法。此外如果钱再多一点，就可以在危险的道路边坡上安装卫星定位设施，如果固定的边坡发生了位移，立刻就发出报警，也能避免后面的车跟着冲下去。但是在省钱的方案上，总有人想进一步省钱。两周之前的6月17日，山东高速安装北斗监测系统的新闻也上了全国热点。济南到潍坊的高速公路，就是为了避免广东那种连续掉车的问题，投入了3亿资金，其中4500万是中央资金，给沿路所有的边坡安装了北斗定位装置。结果大家都看到了：底座的水泥不知道什么标号，反正是用手就能掰开了。这种强度的混凝土，在工程上只能算是水泥砂浆加固。就算上面的北斗定位系统本身没有什么问题，预警信号也没有什么可信度了。很有可能就是监测桩被自己的基础下沉导致异常报警，反复报了几次之后，管理人员会嫌假警报太多，干脆就把整个系统都关掉，3亿的投资就彻底作废了。如果不能消灭类似的问题，就算让电动汽车都来交养路费，山区的高速公路也会越来越危险。

6月14日，中国第一代中西医结合专家许自诚去世，享年103岁。睡前消息往期节目的一个关注重点，就是所谓中医大师的寿命。比如说神医倪海厦，自身懂中医也懂命理，59岁就去世了。同样是中医大师，为什么许自诚先生这么长寿？许自诚先生的长寿秘诀，就是相信科学，相信现代医学。

这里我简单介绍一下许自诚先生。他本来是科班出身的现代知识分子，1950年毕业于兰州大学医学院，是新中国的第一届医学生。大学毕业之后，许自诚留在兰州大学的附属医院治疗皮肤病。直到上世纪60年代，许自诚才接触中医，研究方向也变成了中西医结合。在中医领域，许自诚先生的主要成就是提出脏腑学说。2015年，许自诚在中国中医药报发表文章《脏腑学说是中医理论体系的核心》。请静静来读一段。

<font color = "indigo">我们之所以提出脏腑学说是中医理论体系的核心这一论点，是因为经过系统学习中医理论后，认识到中西医学在脏腑理论上有着相同的解剖学基础，且在生理功能和病理表征的叙述上也没有本质区别。相比之下，脏象学说、经络学说虽然也是中医理论体系的组成部分，但不具有脏腑学说的特质，而阴阳五行学说主要还是一种说理工具，唯有脏腑学说方能够称之为中医理论体系的核心。</font>

任何一个学科，无论学者自己有什么奇怪的观点，只要能够批判同行，敢于正面辩论，就有进步的希望。因为同行之间的争论，能够最快的暴露彼此的弱点，保留真正有价值的东西。许自诚公开说脏象学说、经络学说和阴阳五行都没有什么价值，这说明他是一个有批判性的中医。

顺便说一下，以岭药业创始人吴以岭最核心的著作是《络病学》，属于经络学说。以岭药业每年最盛大的活动，就是国际络病学大会。许自诚比吴以岭大了25岁，算是行业内的长辈。他公开说吴以岭的研究方向没价值，看不到吴以岭来反驳，也不知道他是尊敬前辈，还是院士想避免一切行业内的争论。

许自诚研究中医学术有一个习惯，就是给所有的中医概念都要做出准确的现代定义。比如说中医把胃病分成了胃寒和胃热，许自诚就认为，胃里边的蛋白酶活性太强，就是胃热，会导致慢性的胃炎和溃疡；如果蛋白酶的活性不够，就是胃寒，导致消化不良。为了证明自己的理论，许自诚还专门分析了患者的胃液成分，关注环核苷酸、前列腺素对胃病的影响。

到了具体看病的时候，许自诚的观点是废医验药。2006年，许自诚出版了一本专著，叫《60年行医录》，披露了几乎所有他知道的验方。在全书的前面，许自诚总结了中西医结合的主要用途。请静静帮我读一段。

<font color = "indigo">有些疾病虽无规律性，但在西医尚无理想疗法的情况下，用中药得到了控制和治愈，有借鉴之用。某些疾病中西医都有治疗的方法，但中医的治疗效果显著，且无明显的毒副反应，可作为治疗思路的参考。简单地说，中药能解决问题，可以给西医借鉴；中药有显著疗效，那就给西医做参考。反正要尽量避免中药单独治病。</font>

许自诚披露了这些案例，有几个共同特点。首先，他的病情诊断不靠望闻问切，优先会用现代检查工具，比如说用胃镜去确定病人的问题，这是一个不摸脉象的中医。其次，在具体用药的时候，他不会说什么君臣佐使、补气活血，而是把各种中医药物单独拆开用。

1997年，有一个患者得了慢性萎缩性胃炎，出现了癌症的前期病变。我给大家念一段许自诚的药方：首先用了抗幽门螺杆菌的西药，进行两个疗程治疗，消灭癌症的潜在危险因子；用黄芪、丹参提高患者的细胞免疫功能；丹参用来改善胃黏膜的微循环障碍，促进萎缩腺体的恢复；厚朴、陈皮加强胃的蠕动功能，减轻胃胀、打嗝；莪术用量最多20克，不可再大，否则引起肾损害。试验证明，莪术对各种小鼠移植性肿瘤有一定的抗癌效应，主要成分是莪术醇和莪术双酮。

把中药拆成单独的药材，用现代医学去解释每一种药的效果，甚至算不上废医验药，而是把中草药当成了现代医学的一个分支，这就是许自诚的中西医结合方式。

许自诚先生是科班出身的现代医生，也不相信什么经络学说，那他为什么要坚持中西医结合的研究方向？甘肃中医提到许老先生，往往会引用一个传奇，说许老先生年轻时候曾经得过风湿性关节炎，西医治不好，全靠中医的针灸治愈，从此以后，许自诚主动跑到湖北学了三年的中医，开始研究中西医结合。但是许老先生回忆录里面没有这个故事。

许自诚表示，自己去湖北学中医，是因为1958年被卫生部抽调，参加了西医学习中医研究班。当时毛泽东有一个批示：今后最重要的是，首先要西医学习中医，而不是中医学西医，要抽调100名到200名医科大学毕业生，交给有名的中医，学他们的临床经验。许老先生就是这100多个大学生之一。

屠呦呦的本科专业是药学，主要研究植物化学和药物化学，1959年也进了研究班，比许自诚晚了一年，算是学妹。许自诚、屠呦呦后来都选择了废医验药，用现代医学规律寻找中医的亮点，跟那个中医培训班有很大关系。因为学员都是同时代的现代知识分子，中医这套理论根本就说服不了他们，只有中医的具体药方会对他们有吸引力。请静静帮我读一段中医药网的报道。

<font color = "indigo">中医研究班的84名学员，共分成了8个学习小组，对于学习中医理论遇到不同的地方，主要在组内讨论解决。为什么这样呢？因为当时对学员有个比较特殊的规定。据刘维博回应，当时规定学生只能学，不准问，怕的是西医学员刁难中医老师。毕竟西医与中医是两个医学体系，所以学员遇到难以理解的地方，就可能出现不同的理解。多种因素作用下，中医研究班的学员总体上具有异常浓厚的自学氛围，与极其刻苦的钻研精神。学员在学习期间不准反驳中医，也不准提问题。这个规定是卫生部向周恩来请示的结果，否则就没有办法维持课堂秩序。</font>

从学习效果来看，许自诚很擅长借用中医的药物，但是拒绝了大多数理论，凡是解剖学看不到的，一律不信。不知道有多少中医能够欣赏他的研究模式。

在全书最后，许自诚老先生还分享了一些保养经验。103岁的老寿星给你讲经验，比任何神秘主义故事都值得听。请静静分享几段。

<font color = "indigo">吃食物的时候要细嚼慢咽，不要狼吞虎咽，利于食物的消化，避免再次创伤胃病。要节制饮食，不要吃得太饱，一般八成饱就够了。如果是节假日或者宴会，老年患者更要注意。粗细粮要搭配，鱼、鸭、鸡要吃，但不要多吃，蔬菜水果不能少，牛奶最好要常吃，膳食要力求平衡，讲科学。腊肉、熏鱼、熏肉这些食物可能改变胃的环境，形成亚硝胺，容易引发胃癌。</font>

如果只看这些建议，你完全想不到许自诚居然是一个中医。作为对比，神医倪海厦也有自己的养生经验，我来读一段：在家做菜的时候，买些肥猪肉，自己练猪油来做饭。猪油很香又好吃，我保证不会得心血管疾病。现在人人都吃色拉油，是商人为了赚钱，请西医宣导吃猪油的坏处。中国人吃猪油已经有上千年历史，很多人活过了一百岁，不需要再验证什么。现在很多人都有心血管疾病，就是因为吃了色拉油。只要到医院心脏门诊去做调查，问问大家吃什么油，几乎都吃色拉油。

103岁的许自诚，59岁的倪海厦，虽然都是个例，但是我确信他们的寿命，和各自的养生理念是有关系的。
