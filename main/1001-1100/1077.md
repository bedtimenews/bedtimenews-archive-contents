# 

大家好，2026年8月5日星期三，欢迎收看第1077期睡前消息。请闹闹介绍新闻。

<font color = "indigo">7月25日，新浪新闻报道，河北唐山要求钢铁企业紧急限产，因为现在唐山的钢厂每卖出一吨钢就要平均亏损100元。上个月，界面新闻报道，铜冶炼厂的加工费也跌成了负数。小马，为什么会出现不挣钱也要生产的内卷式竞争？</font>

首先要归咎于政府主导的低效率扩产，其次是因为低效企业无法市场化破产出清。先来说投资效率低下问题。唐山钢铁产业因开滦煤矿而兴起。1925年，唐山炼出华北第一炉工业钢；1979年，唐山钢铁跻身全国十大钢铁公司。1996年，我国常住人口城镇化率首次突破30%，进入快速城市化阶段，房地产带动钢材需求井喷。唐山依托资源禀赋、港口和工业历史，形成了全国性的钢铁产业集群，也形成了生产低附加值房地产建材的路径依赖。对地方政府而言，一个大钢铁项目会立即带来数百亿元固定资产投资和当期GDP、土地整理、园区建设和基础设施投资、就业、税源及上下游企业、本地国企规模和银行信贷扩张。而各省同时扩产导致的钢铁产能叠加过剩问题，不在地方官员决策的考虑因素内：钢价下跌是由全国同行共同承担，这类风险十年后才会暴露，已经跨越官员任期。而且对每个地方来说，我不建，别的城市也会建，我还会丢掉税源和政绩。因此，勇敢投资对个人是高收益低风险的，谨慎不投反而没有可见成绩、无法晋升。在这样的选拔机制下，最擅长承诺宏大项目的人容易胜出，反复提出风险的人则被视为缺少担当。各省市的诸侯经济累加出的钢铁产能有多过剩呢？过剩到2013年以后，中央禁止任何新增钢铁产能。投资的时候都挑简单的干，都希望自己是沿着成熟路线摘取低垂果实的人，都希望别人是冒风险、搞研发、搞产业升级、给未来探路的人。让政府主导投资，结局注定是低效率重复扩产：30年前再给房地产建材提供螺纹钢，30年后还是再给房地产生产螺纹钢。

2024年，全国每生产9吨粗钢就有一吨来自唐山。唐山钢铁集团2024年营收1257亿元，净利润只有10.4亿元，净利率不到1%。2021年，房地产这头骆驼倒了，新冠疫情是压死骆驼的最后一根稻草，房地产用钢量由盛转衰。到这个阶段，本来应该让亏损严重的企业破产重组了，但是我们为了所谓的保就业，为了地方政府必须做点事，为了让地方官员手头有流水，硬生生把破产重组做成了产能置换和退城搬迁。

官员投资项目和普通错误决策最不同的地方，是项目上马后会获得政治身份：地方支柱产业、保就业、保税源、保金融稳定项目、环保改造项目、退城搬迁示范工程。此时再停止建设或让企业破产，已经不只是商业判断，而相当于承认此前的可行性研究报告、审批、贷款和领导决策存在问题；破产清算同时会暴露国有资产损失、银行不良贷款、决策者责任。于是继续追加资源，就成了所有相关方短期成本最低的选项。这就是典型的承诺升级：因为已经投入了100亿元，所以不能停；为了证明前100亿元没有投错，只好再投入20亿元；新投入又使项目更加不能退出。亏损由此不再被当作否定项目的证据，反而被解释成支持还不够、规模还不够、转型尚未完成。一个可以被事实证伪的投资项目，变成了必须完成的行政任务。银行续贷和行政救助继续阻止企业退出，过剩产能长期保留。截至2024年底，唐钢集团资产负债率77%，显著高于全国重点钢企61%的平均水平。这要是放在2014年，是要引起警觉的，现在嘛，我不好说。

所以，唐山卖一吨钢亏100元，不是简单的钢造多了，而是扩张时期形成的高产能、高负债体系，在需求转折后，缺乏量化定损和市场化出清机制。亏损本应促成出清，却为了逃避追责链条，选择继续生产。

<font color = "indigo">就在卖一吨钢亏100元的新闻发布当天，财新发布报道：14次讨薪未果，90后农民工刘某在等待二审判决，案件发生地点，就在卖一吨钢亏100元的河北某地。小马，同一地点同时发生这两条新闻，是巧合吗？</font>

内卷是竞争的恶果，最终由议价能力最低的普通人承担，这是整个故事最讽刺的地方。农民工刘某被包工头杜某拖欠了5万元工资，杜某说总包单位工程款没有下来，给不了钱。刘某打工的项目，是唐银钢铁有限公司退城搬迁项目的高棒车间消防报警工程，高棒车间生产的仍然是房地产建材螺纹钢，所以唐银钢铁没钱结算就不奇怪了。2021年4月，中钢设备有限公司承包了唐银钢铁的退城搬迁项目。2023年11月，中钢设备垫资完成建设，唐银项目正式投产，但唐银公司违反合同约定延迟付款。2024年8月，中钢设备向法院提起诉讼，索要拖欠工程款4.57亿元。中钢设备和唐银钢铁都是国企，如果唐银公司的付款能力没有出现严重问题，中钢不会轻易起诉唐银。从它的第三项诉讼请求——为自己的工程价款申请优先受偿权——也可以看出，它判断唐银公司几乎到了资不抵债的边缘。唐山钢铁产业的积重难返，像一个堆满积雪的山谷，房地产崩盘犹如飘落的最后一片雪花，彻底引发了雪崩，而刘某这样的普通人，是最先被雪崩吞噬的。

我最近刷抖音，刷到对陪审团制度的介绍：当被告人身处绝境，陪审团如果认为换成任何普通人都不可能比他做得更好，判其有罪是不公正的，陪审团可以忽略法官的法律指引，判被告人无罪。我现在头脑很混乱，怎么办？

今年2月底，社科院法学所举办"新形势下文化安全法治研讨会"，会上发布重磅成果《境外视听内容无序传播的文化安全挑战和应对》。研究称，上千部境外影视剧在网络上组织化、规模化传播，冲击主流价值观，危害青少年健康成长。公安大学颜文光讲师说，部分内容暗藏西方错误价值观输出、抹黑我国国情的不良导向，直接威胁到我国的文化与意识形态安全。我已经明显感觉到西方错误价值观对我国意识形态安全的强烈威胁了。在此，我重申社科院法学研究所高瞻远瞩的建议：应该像治理黄色网站一样治理违规网盘、浏览器，把违规境外影视剧全部下架，绝不能让下一代再像我一样经历这种情感上的背叛、精神上的挣扎。
