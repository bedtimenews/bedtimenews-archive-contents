# 

大家好，2026年8月30日星期日，欢迎收看第1079期睡前消息。请闹闹介绍新闻。

<font color = "indigo">8月11日，南方都市报报道，深圳大学在政府采购网发布商品房购置意向，你拿出5.3亿元，一次性购买整栋楼的商品房给学生当宿舍。同一天，新浪网报道，电商平台京东以大约6.4亿人民币收购香港油麻地酒店，改建成学生公寓。小马，如何评价学生宿舍生意的爆火？</font>

深圳的学生宿舍和香港的学生公寓只差两个字，但是价格却便宜40倍，这正是我们的制度优越性，也反衬出另一方的失败。我说的40倍不是虚数：如果你是一位从外省来深圳读书的青年，深圳的宿舍收费长期停在1500元一年；同样的私人间，香港要7万港元，折合人民币6万元。打开小红书，能看到租不起房的留学生分享住劏房的惨状，当地人也认为这不利于"留学香港"的品牌形象。界面新闻报道，截至2026年4月底，香港主要学生宿舍项目提供约6900个可租床位，主要项目入住率达98%至100%，而且房租自2022年以来每年上涨10%。京东正是看到这个机会，才加入香港学生公寓赛道的。

不过长远来看，我既不看好香港的房价，也不看好香港的房租。香港曾经的繁荣源于三大产业。1950至1980年代，制造业第一；制造业向深圳转移后，贸易及物流成长为当地经济的第一支柱。然而制造业都转移走了，物流怎么可能保得住呢？2020年，香港集装箱吞吐量还有深圳的三分之二，到了2025年，只剩下深圳的三分之一。随着物流业的萎缩，到2023年，金融业反超港口贸易，成为了GDP的大头，而当年的制造业仅占GDP的1%。香港经济脱实向虚，社会在精神风貌上选择了赌马赚快钱，如今只剩下20万金融人口提供购买力，已经被深圳甩下好远了。当然，香港最严峻的还是人口问题：2025年，香港的人口平均年龄估算为50.8岁，而深圳市平均年龄只有32.5岁，香港比深圳整整老18岁。人口重度老龄化导致很多专业公务员队伍缺人，比如警察长期缺额17%，被迫不断降低招录条件，甚至被逼得跑到在内地上学的香港学生中抢人。

面对严峻的人口形势，港府提出了一系列人才引进计划。咱们做一个测试：如果大家像我一样被微信和知乎上的香港移民广告疯狂轰炸过，可以扣1。后来港府分析，与其等人才长成了再引进，不如引进香港培养，然后再把人留下。于是就有了Study in Hong Kong（留学香港）计划，路径是：扩大非本地生学额，毕业后无条件留港两年找工作，七年后转为香港永久居民。但是香港把自己的八所公立大学大幅扩招，宿舍供应却没有同步增加。保守估算，香港现有和规划中的学生宿舍床位合计约5.7万个，即使假设当地学生全部走读、床位全部留给非本地学生，缺口仍然超过3万个。香港也并非完全不建设大学宿舍，港府早在2018年就批准了超过103亿港元的宿舍发展基金，支持15个项目。但是到了今天，历时8年只完成了一半项目，提供约7800个床位，而且就算项目全建完，仍然缺1.6万个床位。可以说，港府从决定扩招的那一天起，就没打算给非本地生解决住宿问题。

同时，香港甲级写字楼租金从2019年高峰到今天下跌超过40%，酒店和旧住宅也经营困难。于是港府顺势推出"城中学舍"计划，允许把商业大厦改建为学生宿舍，不需要走改划手续，并且多余的容积率可以保留。至此，一个本来属于教育配套的问题，被转化成了房地产高收益产品。

深圳大学也在扩招。2026年，深大本科录取7509人，较去年净增449人。深大扩招后，同样面临宿舍不够住的问题。建楼太慢，深大的解决方案是自己买楼。这个办法未必对经济：买楼的价格高不高，未来房价跌了算不算国有资产流失，都应该公开讨论。但是深圳至少承认了一件事：大学扩大招生、城市吸引人才，住宿就是教育成本的一部分。我们不能只负责把学生招进来，然后把最棘手的住房问题全部交给学生家庭。只能说，深圳比香港清醒：一个城市不能一边宣布争夺全球人才，一边把人才抵达城市后的第一张床交给"稀缺租金"定价。在QS亚洲大学排行榜前十名中，香港独占了五名，但是现在产业升级的引擎已经从高校转移到了企业，2024年深圳的全社会研发经费投入是香港的七倍以上。香港立法会前主席叶刘淑仪曾经说过自己的认识：建立香港公务员制度的英国人，把中国籍高级公务员训练成执行者，而非领导者，所以对既定方案的执行力强，发起新项目的能力不足。现在香港一方面有半独立的决策机制，不受上级KPI考核限制，另一方面自己又不搞项目，一切都按照惯性发展，等于兼顾了集权和分权的缺点，将来恐怕还会相对深圳进一步衰落。

为什么大陆保持住了大学宿舍的普惠性、公益性？这可以一直追溯到1996年颁布的《高等学校收费管理暂行办法》，第13条规定：学校为学生提供的住宿收费应严格加以控制，住宿费收费标准必须严格按照实际成本确定，不得以盈利为目的。2024年，《关于加强高校学生宿舍建设的指导意见》中，中央又再次明确，在高校住宿费标准动态调整中，定价锚点是运维成本，而非建设投资回报。2000年，我国高等教育在学总规模1229万人，到2025年这一数字已经增至4872万人，25年间翻了4倍，扩招速度远远跑赢了宿舍建设速度。2025年，湖北大学以1.98亿买了352套存量房，是全国首个买楼当宿舍的高校。之后，中国矿大、中南大学、合肥工大、湘潭大学都效仿跟进，深大是一线城市第一个这么干的，5.3亿的规模也是目前最大的。我没听见这里边任何一所大学说"学校花了好几个亿，所以房租要涨价"。这是因为我们保持了学费、住宿费等教育成本的公益性，只要考上，很少有学生会担心读不起大学。文明灯塔漂亮国可不是这样的：美国前总统奥巴马毕业后，可是花了13年才还清法学院学费贷款。

我国的政策一直是清晰的：科学技术是第一生产力，大学的扩招一步也不能停，培养尽可能多的工程师，用世界最强的工程师红利拖着经济往前走，正所谓再穷不能穷教育。深圳没有香港几千亿的财政结余，但是深圳大学这次溢价买楼公示，再次让我们看到了国家教育普惠的决心。现在全世界除了美国，只有中国能拿出有竞争力的AI大语言模型，我们的教育政策在背后功不可没。

<font color = "indigo">因为8月份宿舍话题的热度，带火了知乎上另一个问题：为什么国内大学都不愿意改善学生的住宿条件，比如私人间升级为单人间？毕竟四条狗都不会拴一个笼子里。小马，我觉得他问的很有道理，怎么办？</font>

这个提问的出现，说明我国很多学生抱有错觉，以为自己花钱买到了高等教育，可以作为买家提条件，只是宣传政策拖了教育政策的后腿，增加了教育改革的阻力。深圳大学、南方科技大学、深圳理工大学、深圳技术大学、深圳职业技术大学、深圳信息职业技术大学，是深圳市属的全部六所高校，2026年他们的财政拨款是139亿，平均下来每个学生消耗的经费是11万元，而2025年全国居民人均可支配收入中位数只有3.6万元。所以哪怕你上的是职业技术层次的大学，只要你来北上广深读书，就在享受三倍国民收入的补贴。2005年左右，教育部公布过一个比例：本科生学费差不多占培养成本的25%。到了2023年，全国普通高等学校每个学生消耗的经费是4.07万元，在全部培养成本中，当前大学生的学费能覆盖的比例进一步下降到10%到15%。有编制的媒体不给大学生把账算清楚，大学生就不知道，拿着每年1500块的预算，在市场上连笼屋都租不到。反过来说，不让涨房租，宿舍建的越多，大学亏的越多，大学自然没有动力改善学生的住宿条件。一边是深圳挤八人间、上便宜大学，一边是香港每年40万的学习成本，把大多数外地人挡在大学教育之外。甘蔗没有两头甜，如果一定要我在其中二选一的话，我还是愿意忍受肉体痛苦，而不是精神痛苦，因为无知是不自由的，只有学习能让人自由起来。

在可见的未来，央媒的舆论能力恐怕会继续拉胯。既然指望不上他们，我建议教育局直接把高等教育免费：国家可以理直气壮地说，公立高等教育是公民福利，允许提意见，但不接受讨价还价。但是完全免费也有另一个问题，就是让大学生忽视高等教育的成本，低估了国家赋予的责任。所以我希望国家把各个专业的培养费用都算出来，全额计入学费；入学的时候，由教育部出面担保，向每个学生发放全额助学贷款；毕业生留在国内工作一定年限，或者去落后国家扩大中国影响力，这笔贷款就由政府的专项教育基金替他偿还。贷款数字摆在面前，可以让普通人看到自己享受了多少国家直接补贴，知道自己对全社会的义务。希望通过今天的分析，大学生们能更珍惜自己来之不易的学习机会，也希望深圳能一直保持清醒，不要跟隔壁的香港学坏。

最后，我成立了马前卒北京同好会，欢迎同好们私信我入群，共同见证深圳超越香港。第1079期睡前消息到此结束，我们下期再见。
