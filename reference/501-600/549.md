# 

大家好，2026年的第一个星期一，欢迎来到第549期参考信息。

老话说旧的不去，新的不来，很多问题就出在旧的不去。武汉大学社会学院教授吕德文最近发文，马上2026年了，有些地方还在执行特殊规定。北方某大城市的中小学和政府机关，教师和基层干部假期外出仍要填写离城报备表。

多年来，每到节假日，该城市基层单位都会按惯例发通知提醒，非节假日不能擅自离开所在城市，假期若要外出离城，必须提前申请报备。这项起源于特殊时期的制度，如同一个被忘记拆除的拐杖，仍牢牢附着在组织的日常运行中。

比如一位普通街道干部计划元旦去临省休假，需要获得科室负责人、分管领导和主要领导批准才行。制度早已失去实际意义，只要是法定节假日，领导一般都会批准，特殊情况如紧急返乡奔丧，哪怕来不及申请，亦可事后补办。

然而仍有种种不便。有些接到要求书记和主任同时签字，但领导常常不在，便无法完成签署。虽然可以变通，却增添了不必要的麻烦。执行松紧不一更是增添了荒诞性，多数情况下，不报备也不会产生后果，但一旦遇到上级巡查，意外便随之而来。某学校近期接受巡查时，就被指出离城备案制度执行不到位，要求整改，老师们又好气又好笑。

这种整改，质疑上级显然不妥，但认真执行，分明是在强化形式主义。于是单位领导一本正经批判老师不守规矩，老师强忍着笑，接受批判。制度虽然已成为典型的鸡肋，但因为仍然存在，且上级还当回事儿，谁也不敢公然无视。

疫情结束已数年，这项特殊时期的制度却奇迹般地延续下来。基层私下抱怨不断，却鲜有人公开提意见，上级部门也无意主动清理。恰如一位受访者所言，大家都习惯了，配合领导，省得麻烦。

这种疫情管理后遗症正在以多种形式显现。同样在这个北方大城市，绝大多数高校仍在封闭式管理。这些临时手段在行政体系中逐渐常规化，甚至异化为形式主义的合规程序。在方便自己、麻烦别人的上位者思维作祟下，社会管理反而变得僵化。

过去人们可以通过无声的抵抗，让不合理的政策没有存在空间。比如越来越多的人不履行报备手续，单位也发现似乎没有意外发生，政策自然就终止了。麻烦在于现如今的异议成本高昂，提出合理意见者未必会获得单位认可，因此基层的抱怨在私下流行，却始终难以转化为公开建议。于是荒诞的制度一方面被人们私下议论，甚至在全国为众人所知，略显异类，但在本地却得以在集体沉默中应付式运转多年。

在黑龙江同江市，一份废止的文件却成了市政府向村民征收土地租赁费的依据。起源是2012年市政府下发《同江市国有土地管理暂行办法》，要求5个乡镇的85个行政村农户家庭承包的耕地，除每口人留15亩口粮田不收费，其他每亩需缴纳国有土地租赁费60元。

而村民们出示的1983年政府颁发的土地证，土地性质清楚写着集体土地。实行联产承包责任制之后，两轮土地承包中，村民都顺利拿到省政府制发的土地承包经营权证，现在第二轮承包30年还没到期，可是承包土地的性质却被改变了。

有村民表示，1996年同江市政府以换发土地证为由，通知村民把旧的土地证交上去，不少人交了，但是新证一直没发下来。后来政府出了份文件说旧证作废了，文件是1996年市政府出台的《关于进一步明确我市土地资源权属的决定》，宣布原土地证无效，把集体土地变成国有土地，涉及范围上百万亩。一开始是一亩地60元租金，后来涨到90元、160元，这些年土地租赁费收了十几亿。

东五乡85个行政村的村民一直在申请政府公开变更土地性质依据的相关文件，但同江市政府和市自然资源局都答复，没制作、保存或获取土地变更文件，还相互踢皮球。省自然资源厅也回复，没有批准将集体土地征收为国有土地。

后来村民们发现，1996年的那份向他们收租的依据文件在2010年已经被废止了。而村民提出行政复议时，同江市政府仍然还拿着这份早已废止文件来作为自己变更土地性质的依据。目前只有同江市自然资源局法规股股长曹磊解释说，这些地一直都属于国有土地，因此不存在变更，也就没有相关的变更手续和批准。

按照土地登记办法规定，土地性质在土地登记资料中有明确记录，到底是国有还是集体，一查就明确。而记者提出希望查询原始登记和土地规划时，曹股长表示，因为这里属于中俄边境，资料保密，不能提供。但村民十分不解，发给我们的土地证上清楚地标记着每个行政村的面积、方位，早就已经公开几十年了，有保密的需要吗？而且土地性质需要保密吗？对谁保密？这个事件现在还没什么后续。

内需、消费是开年以来的关键词，而零负债人群近期走红网络，频频登上各大平台热搜。这一群体的核心特征在于，以理性规划确保财务安全与生活从容，坚持财务绝对安全原则，在消费选择上更注重必需品的性价比，主动回避奢侈品、面子工程等高溢价消费。由于经济压力较小，这部分人群拥有更高的时间自主权，可将精力投入学习、转行或阶段性休整，甚至获得更稳定的睡眠质量。

比如楼先生在疫情期间果断放弃了买房计划，由于没有大额支出，他逐渐成为零负债人群的一员。他形容自己当下的生活状态为“高自由、不迁就”。消费上，他始终将精神需求置于首位，以盆景鉴赏为核心，辅以扇子、收藏等兴趣爱好，对物质生活并无过高要求。即使未来收入水平提高，他也计划维持当前消费结构，不因收入增长而显著调整生活方式。

另一位投身非遗领域的90后创业者，曾是某大型互联网企业的游戏设计师，长期在超一线城市工作生活，但高昂的居住成本让他倍感压力。离开超一线城市后，他实现了零负债，得以全身心投入非遗产业推广，但相关业务要达到稳定盈利水平，仍需要时间和积累。

中银消费金融联合时代数据2021年发布的《当代青年消费报告》显示，全国约有1.75亿90后，其中只有13.4%的年轻人处于无负债状态。尼尔森2019年发布的数据显示，中国90后整体信贷产品渗透率高达86.6%。

今年国家继续实施扩大内需战略，因此如何撬动零负债人群、释放消费潜力颇受关注。随着经济发展和人均收入水平提高，我国居民消费结构由生存型转向发展型，由商品消费向服务消费拓展。相较于大额耐用品消费，服务消费在降低心理负担的同时，更有可能撬动零负债人群的消费需求。

新质未来研究院院长、经济学家张奥平表示，只有让零负债人转变为零忧虑人，消费意愿才有可能真正提升。要激活这部分人群的消费潜力，关键在于将更多政策资源投资于人，应提高养老、托育、医疗等民生领域投入比重，完善公共服务体系，增强居民对未来的确定性预期，从而改善消费环境。12月中旬，发改委党组在《求是》上发表题为《坚定实施扩大内需战略》的署名文章，指出从现实看，我国在公共服务和社会保障领域仍存在短板，养老、托育、医疗等公共服务供给仍显不足。

近日，一名外卖骑手发布的对比视频火了。淘宝闪购骑手端的计时器走完了一分钟，而另一台手机的时钟才过去42秒，整整18秒的时间差，引发骑手群体集体质疑淘宝闪购偷时间。对此，淘宝客服回应称，会持续优化改善，进一步核实处理。网民称之为新形式的“半夜鸡叫”，背后是劳动者权益和算法伦理的冲突。

有骑手吐槽，平台表面上说不扣超时费了，看上去很人性，可暗地里却把时间缩短了整整30%，这种变相的提速是把每一单都逼得更紧了，压力全转嫁到了骑手身上，非常地不厚道。在黑猫投诉平台上，已经堆积了大量配送时间不合理的投诉，而申诉难如登天，申诉机制往往形同虚设。而淘宝平台客服的回应含糊其词：已收到反馈，将优化系统，无法确认是否存在人为干预计时逻辑的情况。

从技术视角解释，设备性能不足可能导致视觉误差，旧型号手机同时运行多个应用时，后台卡顿可能造成计时器跳秒。但更大的疑问在于，为何平台没有主动为这种情况提供明确说明？技术解释的缺失，让可能的设备问题也被裹挟进算法压榨的叙事中，加剧了双方的不信任。

在消费者一端也有被偷时间的问题，不过是相反的。几个月前，有网民发现视频软件上的广告时间被拉长，30秒的广告得放接近50秒才结束，有的倒计时倒一之后，竟然硬生生停住了，直接卡在了广告即将结束的界面上，还引得市场监管总局下场回应视频平台广告时长与标注不一致。时间的流逝按说是最客观的，但是如今却充满了算计。

境外社交媒体上也曝光了一起类似事件。某大规模送外卖的APP会根据司机在晚上10点以后接单数目和速度，来判断他有多么饥渴地需要钱，所谓“Desperation Score”。一旦被打上这标签之后，系统就会自动把利润率最低的单子都送给他，反正知道他不会挑拣，会照单全收。这就是人善被人欺在算法上的自动化大规模实现。

继续关注人口小县改革。云南日报、云岭先锋等云南官媒近期持续刊文介绍改革成果。云南共有漾濞、永仁、西盟、贡山、德钦五个人口小县，漾濞和永仁被选为试点。两县都立足自身特点，推动机构设置与发展需求精准对接。比如永仁县立足产业发展，优化设置了人社局、民政和退役军人事务局、卫健局；漾濞县立足文旅定位，将体育职能划入文旅局，推动文旅体深度融合。

漾濞县党政机构由33个精简至25个，内设股室压减30%以上。永仁县实现一类事项由一个部门统筹，一件事情由一个部门负责，全县党政机构由35个精简到25个，内设机构减少约21%。

机构整合带来行政效率明显提升，群众办事也更方便。比如司法局与政法委合署，综治、信访、调解等功能一站式集成，群众解决纠纷只跑一次；退役军人事务职责划入民政局后，退役老兵、困难优抚对象办手续、享政策，一个部门全搞定。

部门合并后办公经费更节约，办公用房、车辆等资产整合腾退。漾濞县减少了1700多平方米办公用房，每年运转经费节约274万；永仁县减少4500多平方米，每年省500万。永仁县还将机构撤并腾退出的办公用房改成工人住宿楼，全县开展7个工人住宿楼改造项目，总计改造2万平方米，解决3500多名产业工人的住宿问题。

2024年以来，按照中央部署，结合地方机构改革，共有97个人口小县开展机构改革，重塑小县治理体系。不过改革中较为普遍的路径是大部制改革，整合程度更高的撤县并县改革未在实践中推开。中南大学学报社会科学版2025年10月刊发文章，比较了这两种路径的利弊：大部制改革的局限性在于，块块合并后的部门与条条职能部门的隶属关系仍不清晰，条块矛盾依然存在，责任边界也较为模糊；撤县并县的局限性在于，公共服务供给面临着服务人员少、服务对象多、服务事项广的困境。文章建议，对地理位置相近、资源禀赋相似、发展水平相当的县，可考虑撤县并县，发挥规模效应；在部门职能交叉、基础设施关联度高的领域，可尝试大部制改革，强化综合管理。

最后关注宗教协会改革。中国佛教协会和中国道教协会近期分别举行全国代表会议，选举产生新一届理事会、常务理事会。值得注意的是，还分别成立了第一届监事会。

中国佛协第一届监事会监事长为正慈法师，是湖北省佛教协会会长、黄梅五祖寺方丈、黄石东方山弘化禅寺方丈。此番当选监事长后，他不再担任中国佛教协会副会长。中国道协第一届监事会监事长为黄至安道长，他曾任湖南省道教协会会长、南岳衡山道院方丈、南岳坤道学院院长等。

在现代组织治理中，监事会不是新鲜事，但在全国性宗教团体中，具有明确制度定位的监事机构并不常见。两大宗教协会监事会的设立，显然与近年来宗教界的腐化案件有关。而正在少林寺主持整改的印乐法师，此次当选中国佛协副会长。

此外，中国佛教协会理事会日前通过《汉传佛教活动场所主要教职任职办法》，废止了《汉传佛教寺院住持任职办法》，主要区别是在住持任期、年龄方面都做了明确规定。原先的《汉传佛教寺院住持任职办法》规定，住持每届任期五年，可连选连任，已连任三届确需继续担任住持的，在履行任职备案手续前，应报所在地省区市佛协同意，汉传佛教全国重点寺院还应报中国佛协同意，75岁以上的教职人员原则上不再担任新一届寺院住持。

新的《汉传佛教活动场所主要教职任职办法》规定，汉传佛教全国重点寺院的住持人选，在履行任职备案手续之前，应由其所在地省、自治区、直辖市佛协提出审核意见，并报中国佛协同意。汉传佛教全国重点寺院的新增名单，由中国佛协提出。住持每届任期五年，同一佛教活动场所连续任职不超过两届，累计任职不超过三届。

住持每届任期届满后，应对其进行财务审计，财务审计不合格者不得连任。在同一佛教活动场所连任住持十年以上者，除本办法第六条第三款规定的情况外，任期届满后不得连任。住持任期届满后，到其他佛教活动场所担任住持的，其任期重新计算。七十周岁以上的佛教教职人员，不再担任新一届住持。宗教治理也要迈向制度化新阶段了。
