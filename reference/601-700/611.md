# 大家好，我是小黛，欢迎来到第611期参考信息。

首先关注湘雅二医院项目招标争议。中南大学湘雅二医院拟建国家紧急医学救援基地，工程估算总投资8.27亿元。今年3月17日，建设施工总承包合同公示，意味着招标完成了最后一步。

但多家投标单位反映，最终中标单位湖南省第四工程有限公司联合体，在去年10月首次候选人公示中只排第八。2025年12月的二次公示中，首次公示的六家中标候选人被全部更换；二次公示后，第八名逆袭成为中标者，引起多家企业抗议。

今年1月，招标方曾公告称因收到投诉暂停招投标，并把投标期限延长90天至4月27日。但两个月后的最终合同公示，中标方仍是二次公示中的湖南四建联合体。程序之外，中标方的资质也存在争议：投标期间，湖南四建刚因工程质量问题被处罚，并在湖南省第一批建筑市场责任主体不良行为中被公示；联合体成员江苏和天下节能科技股份有限公司则被指未按要求在湖南备案。

澎湃新闻报道后，湖南省发改委6月6日通报，省委、省政府高度重视，已成立联合调查组开展全面深入调查，结果将及时向社会公布。最关键的问题仍是：最初排名第八的中标候选人如何逆袭，中间到底发生了什么？多家参与投标企业称，在填写同意延期回复函后，并未等到重新招标，而是直接沿用了前期结果；其投诉也没有得到回复。

《招标投标法实施条例》规定，投标人或者其他利害关系人对依法必须进行招标项目的评标结果有异议，应当在中标候选人公示期间提出；招标人收到异议后三日内应当答复，答复前应暂停招投标活动。招标信息公开的初衷，是保障公平竞争、防治腐败，方便参与者与公众监督，尽可能挤压利益输送空间。若关键信息缺失，外界又该如何监督？

近期，四川稻城亚丁景区截断省道收费也持续引发热议。5月下旬，博主吕大侠V50发视频称，景区将S462省道通往亚丁村的部分路段截断，要交120元观光车费才能进入。他认为不合理，要求景区出示相关文件，最终签署免责承诺书后驾车进入。随后景区通报，工作人员因违规放行博主自驾进入已被严肃批评并依规处理；但对截断省道收费这一核心争议并未正面回应。

把摆渡车费异化为“第二张门票”并非这里首创，河北张北草原天路、山西五台山景区、云南泸沽湖景区等都曾陷入类似争议。稻城亚丁这条路原本是随旅游兴建的通村土路，2013年至2022年由亚丁景区管理局使用、管理和维护，2022年升格为省道，日常养护由财政出资。四川交通厅工作人员称，公路法禁止的是非法设卡，亚丁管理局作为甘孜州政府派出机构，根据自然保护区条例对社会车辆进行管控，理论上不属于违法。景区旅游开发公司则称，争议费用并非道路通行费，而是游客乘坐景区摆渡车的交通服务费。

不过，稻城县发改局长承认收费有不合理之处。交通服务费定价固然应考虑前期投入成本，但计价成本应严格核定；修路主要依赖国家财政。5月底，甘孜宣布整治稻城亚丁景区问题，观光车及电瓶车暂停收费。整改前，景区核心区域强制乘坐摆渡车，园内交通分段收费，观光车票120元、电瓶车票70元。争议表面是公共路权之争，实际也暴露出一些县域文旅把公共资源变成地方创收载体的问题。

一年来一直颇为高调的追觅创始人兼CEO俞浩，6月5日被微博禁言，具体原因未知，其他社交账号仍正常。加上此前“崩老头”争议，追觅的商业模式来到风口浪尖。

俞浩1987年生，毕业于清华航空航天专业，在校期间创办科技平台天空工场，2017年成立追觅。核心创始团队大多来自清华，以吸尘器研发制造起步，自称“造飞机的人去扫地”。2023年以来，追觅业务加速扩张，产品从清洁电器延伸至割草机器人、泳池清洁机器人、厨房家电，以及汽车、手机、无人机、电动垂直起降飞行器等；还涉足智能戒指、3D打印机、录音卡片、AI智能眼镜、骨传导运动耳机、农业机器人、矿业机器人、芯片算力、咖啡、奶茶、潮玩和在线旅游平台等领域。俞浩曾称，追觅有200多个事业部，每一个都要对标一家独立上市公司。

这些扩张资金主要通过天空工场创投基金获得。该基金由俞浩于2023年设立、大学同学雷鸣负责，对外宣称为百亿级基金，但运行模式更像专为自身孵化项目寻找资金的财务顾问。孵化项目早期在追觅体系内发展，资金也主要来自追觅；融资后转为天空工场创投持股，追觅不再持股。俞浩和雷鸣解释，这种安排是为了规避潜在利益冲突、保障产业链合作关系；但追觅早期股东提出异议，认为追觅出资培育项目却未获得相应股权回报。

天空工场创投的主力资金来自各地国资。各地政府成为合伙人的同时，追觅宣布投资设厂或与当地既有产能合作，已落地地区包括浙江杭州、绍兴、丽水，江苏苏州、宿迁，四川成都青白江，湖北武汉东西湖，安徽滁州、山东枣庄等。财经自媒体曾将这种模式概括为“崩老头”，认为其与地方招商、国资投入之间的关系值得追问。财联社近日报道，长三角某市辖区要求统计当地企业与追觅合作情况，包括合作项目、总体规模、资金投入、财政与国资投入、经营情况等；追觅人士称，这是常规检查，官方暂无回应。

追觅模式的争议，还触及一个容易出风险的财政领域：地方政府股权投资。国办日前公布《关于加强监管防范风险促进私募投资基金高质量发展的指导意见》。尽管文件规范的是私募行业，最受关注的仍是国资基金。近年来，以央国企、政府引导基金为代表的国资LP在私募基金中的占比不断提高。截至2024年末，全国政府引导基金有2178支，目标规模约12.84万亿元，已认缴约7.7万亿元；截至2025年底，县级政府投资基金超过千支，规模超万亿元。

文件提出严控新设政府投资基金，县区原则上不得新设，确有必要新设的应报上级政府批准。部分政府和国企投资基金偏离功能定位，募投管退各环节均有短板，出资人责任落实不到位；部分私募基金还成为违法犯罪、新型腐败和隐性腐败的工具。现实中，县区层面的基金容易异化为变相举债或融资通道、变相补贴或抢项目的现金武器，以及“设了不敢投、投了不会管、管了退不出”的面子工程。股权投资回报周期往往要七年甚至十年以上，远长于土地出让当年变现；许多县级项目缺乏清晰产业定位和相应人才，指望基金创造财政收入，往往只是镜花水月。

一年前，售价3000元左右的华为智能手表可用医保购买，一度引发热议，原因是其被算作二类医疗器械；如今这类做法将告别医保。国家医保局、财政部近日发文，要求建立定点零售药店个人账户支付白名单制度。白名单内的项目，个人账户在定点药店可以支付；白名单外项目不得支付。

文件要求，保健品、日常生活用品、家具、家用电器、牙膏、牙刷、牙线、面膜、化妆品、隐形眼镜、按摩设备、智能通讯设备，以及主要用于体育健身、养生保健等生活功能、医疗附加值较低的器械耗材，不得纳入白名单；还要防止仅为适配医保支付、无实际医疗价值或实际医疗价值较低的“马甲产品”进入医保。医保局近期连续公布多地八起药店骗保典型案例，包括买香菇、大枣、牙膏、荔枝也能刷医保，以及串换药品、销售回流药等。

另一方面，异地就医结算有望更加便利。职工基本医疗保险个人账户跨省共济经办规程日前出台。异地工作的参保职工，可以让老家更多亲属使用自己的医保个账余额。此前，职工个人账户常年有结余，户籍地的父母、子女看病买药却可能需要自费，地域分割导致“卡里有钱，家人难用”。新规把共济范围从配偶、父母、子女三类亲属拓展至兄弟姐妹、祖父母、外祖父母等八类近亲属，并支持一人绑定多名亲属、一名亲属接受多人共济。

最后关注河南60岁低保老人“被贷款”20万元一事。南阳市唐河县村民小邢反映，其60岁的低保户叔叔邢民金莫名背上20万元贷款，到账当天就被转入陌生账户并提现，去向不明。邢民金多年低保金持续被扣作还款，日常只能靠借钱度日，直到2025年底小邢帮忙取钱时才发现账户异常。

小邢还发现，自己的父亲2012年也曾被贷款29万元，担保人为邻村村民；但该村民查询征信后发现，名下竟有两笔本人毫不知情的担保记录，其中一位贷款人他根本不认识。邢民金没有上过学、不识数。一名担保人邢万坡曾任村会计，2021年带邢民金到唐河县农信社办理业务。邢万坡称，贷款是应银行工作人员要求办理的，对方让他找一个“单身穷的”来办，于是他找了不识字、经济困难的邢民金。

贷款银行的个人客户信贷业务调查报告称，邢民金有价值35万元的房产、10万元私家车和10万元存款，但被指与实际情况不符。媒体报道后，唐河县全面排查整治“被贷款”问题，共发现三人三笔借名贷款，合计79万元；相关贷款户涉嫌借名骗取贷款，农商银行工作人员涉嫌违规操作，已处理15名相关责任人，涉嫌犯罪的移交公安机关进一步调查。涉事群众相关贷款及被自动扣划的低保金已全部追回，失信被执行信息也被删除。

看看新闻就此提出疑问：15名被处置者分别是谁，违法事实为何被淡化？当事人不会写字，合同上的签名被指是被人握着手伪造，这早已不是普通业务失误；骗局由谁主导、谁经手、谁获利，都应说清。老人征信中凭空出现虚假资产却能绕过层层审核，是失职躺平还是内外串通，监管漏洞也必须摊开细说。
