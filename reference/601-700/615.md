# 

大家好，我是小黛，欢迎来到第615期参考信息。

继广设马院之后，辅导员学院来了。6月15日，阜阳师范大学辅导员学院揭牌，这是安徽首个大学辅导员学院。辅导员学院为校内教学研究机构，不设行政级别，挂靠学生工作处。学校成立由书记、校长任双组长的建设领导小组，多部门共同参与。学院由分管学生工作的校领导任院长，学工处长兼任执行院长，下设办公室、辅导员发展中心、辅导员研修中心、学生工作方向团队、咨询指导委员会等机构，均不设级别。

辅导员是极具中国特色的制度，《普通高等学校辅导员队伍建设规定》中明确，辅导员是开展大学生思想政治教育的骨干力量，是高等学校学生日常思想政治教育和管理的组织者、实施者、指导者。去年5月，教育部首次将高校专职辅导员队伍提升至与教学、科研、管理队伍同等重要的“第四支队伍”战略高度。教育部思想政治工作司司长在今年第二期《中国高等教育》杂志发文，要优化培养培训，整合优势资源建设高校辅导员学院，分层分类开发能力素养提升核心课程体系，建设系列微专业。

近期辅导员学院组建迅速。仅在4月份，就有西南民族大学辅导员学院揭牌，是四川首家；广西民族大学辅导员学院成立，是广西首个；西安培华学院辅导员发展学院揭牌，是陕西首个；还有福建三明学院辅导员学院和山东师范大学辅导员发展学院成立。5月，新疆首个辅导员学院在喀什大学揭牌。6月初，湖北首家辅导员学院在湖北第二师范学院成立，海南首家辅导员学院在海南外国语职业学院挂牌。

光明日报报道称，辅导员学院纷纷成立无疑是件好事，但叫好之余也要认识到，目前其建设仍处于探索阶段，要实现长效发展、释放持久活力，还需在内涵建设上持续深耕。

过去辅导员的职业发展路径较为狭窄：走专业技术职称，科研成果难以与专业教师竞争；走管理职级晋升，又缺乏行政岗位的积累优势。如果进了辅导员学院，修了学分、考了证书，到头来职称还是万年讲师，职级还是原地踏步，那这样的学院很可能沦为空中楼阁。也有辅导员坦言，希望培训不要成为第二张课表。辅导员的日常工作早已饱和，若学院培训变成密集排课、打卡签到的形式，非但不是助力反而会增添负担。

高考结束后，多所高校近期发布2026年本科生招生计划，上海交大、北航、南大、中国农大、中央财经大学、南开、中山大学、山东大学等双一流都明确本科招生扩招。

除了整体的扩招，具体专业的扩招也引发关注。比如在大湾区，南方医科大学本科扩招60人，广州中医药大学扩招200人，广州医科大学扩招50人，广东医科大学扩招100人，且新增名额极少倾斜传统临床，大多投向新医科交叉领域，被解读为医学教育的重心正在从培养更多医生，转向培养更复合的医学人才。

以往学医主要是理科生的专利，今年中医类专业选科限制大为放宽。南方医科大学的中医学（名老中医传承班）、中医学、针灸推拿学，在3+1+2省份物理类历史类均不限选科，在3+3省份同样不限选科。广中医今年近半数招生专业不限选科，中医学、针灸推拿学、中医骨伤科学、中医养生学、中医康复学等专业全部放开约束，当然对于一些临床专业，物理类是必选。选科放宽为文科生打开了大门，但现代医学课程体系中的解剖学、生理学、生物化学等均对理科基础有较高要求，文科生入学后需尽快补齐短板。

多所高校还大幅放宽转专业限制。南方医科大学尤为宽松，临床医学类、口腔医学类专业按比例有条件转入，其他专业开放转入，不受高考选科限制，成绩也不做限定性要求，共有三次转专业机会，可在新生报到后一个月内、本科一年级以及本科二年级申请。天津医科大学同样是转出零门槛，学生只需满足转入专业的选拔条件，就可以调整专业。学生入校后还可参加二次选拔进入各类特色创新班，广中医就开设了岱翰班、国维班、林毅班等国医大师特色班级，以及深圳创新班、博医班等优质培养项目。

这意味着即使高考时未能直接进入理想专业，在校期间仍有充分的机会调整方向。如今想进三甲医院，博士学历是基本门槛，所以很多高校推出长学制的创新班、特色班等，希望系统整合本科与博士阶段培养资源，缩短培养周期。医学专业扩招、选科松绑、转专业放开，确实是为更多考生打开了学医的大门，但医学生培养周期长、学业压力大、职业责任重，这些客观现实并不会因为招生政策变化而改变。

医生飞刀费直接入私囊的行业乱象有望终结。国家卫健委时隔21年修改部门规章，明确医生外出会诊费应由公对公支付，医生需要依法纳税。飞刀是指医生利用休息时间到其他医院做手术的行为，能让优质医疗资源下沉，患者就近得到救治，堪称多赢，但是灰色地带始终困扰着医患双方，曾有患者手术后举报医生飞刀。15日，卫健委公告修订医师执业注册管理办法、医师外出会诊管理暂行规定、医师资格考试违纪违规处理规定。修改后的医师外出会诊管理暂行规定明确，会诊医疗机构应当建立医师外出会诊费用分配制度，给付会诊医师合理报酬并依法纳税。原文件是2005年出台的，要求会诊费用按照邀请医疗机构所在地规定执行，但现实中经常绕过正规收费系统直接付给医师本人，除了造成税收损失，由于私下交易往往缺乏有效凭证，一旦发生医疗纠纷，医患双方维权还将面临举证困难。这次修订除了强调医生需要依法纳税，还明确了医生所属医疗机构和会诊医疗机构的监管责任。

近年来飞刀逐渐获得了正名，河南、广东中山、浙江温州等地定调飞刀适当收费合理合法，温州市中心医院还出台院外专家会诊费标准，价格最高的省外专家四级手术院外会诊费为15000元。今年2月，国家医保局表示，专家异地坐诊的，执行邀请方医疗机构所在地的价格政策，按相应职称级别收取门诊诊查费；医疗机构邀请外地专家前来本院会诊，按照上门服务费加会诊费方式收费，上门服务费按受邀地医疗机构自主制定的收费标准执行，会诊费按照就诊医疗机构所在地价格政策执行。修改后的暂行规定进一步提出，会诊医师享有获取劳动报酬的权利，且应当体现其职业特点和技术劳动价值，在法定节假日完成会诊的，会诊医疗机构应当按规定提高报酬标准。

飞刀可由医患任一方发起，除了会诊费，差旅费的标准与票据合规性也存在一定灰色地带。比如药械企业常以支持学术交流为由，承担专家的差旅住宿甚至手术耗材费用，以会诊之名行贿赂之实的现象已经引起监管关注。卫健委等十四部门近日明确，医务人员违规多点执业或外出会诊，以及借参加学术活动接受非法利益输送的问题，是今年医药反腐纠风重点之一。

黑龙江七台河女子回乡考编排名第一却被别人递补一事持续引发关注。王依1990年出生，中医专业大专学历，在北京杭州等地医疗机构工作多年，2022年回老家勃利县结婚生子，去年报考桃山区桃北社区卫生服务中心中医医生岗位，今年1月以综合成绩61.13分位列岗位第一，出现在拟进入考察人员名单。然而公示期后却没能等来入职通知，桃山区政府4月公告，另一名考生以57.78分进入考察与体检名单。在王依多次维权之后，该岗位本月被直接公告取消了。

面对质疑，官方的解释是审核失误。人社局称，因为相关人员把关不严，让只有执业助理医师资格的王依进入了需要执业医师资格的考试直至公示环节。第一财经评论，“失误说”虽然听起来离谱，但并非完全没有可能性，从报名审核、现场资格审查到笔试面试，任何一个环节的审核人员出现疏忽，理论上都可能导致这种结果。然而网友普遍不买账，各个社交平台评论区高度一致的猜测是，这本是一次萝卜招聘，奈何萝卜未入坑，才有了后面一连串奇葩操作。后续，卫健局表示，资格审核把关不严的工作人员，因为涉及违规违纪，已被立案调查。

新京报评论，但这样的处理令人困惑，既然在公示后发现不具备报考资格，而取消其入职，为何不及时向其做出书面说明并公告，却要这般遮遮掩掩？尤其是招聘公告称不进行递补，但还是进行了递补操作，这也是解释不清的。在当事考生维权之后，当地成立化解专班处理，提出“三不行、三行”方案，成立专班说明高度重视，然而这种处理结果给人的感觉却是“继续遮掩”“息事宁人”。当地如果一开始就承认问题，公开处理，而不是和当事考生私了，事情或许不会搞得这么难以收场。更加让人大跌眼镜的是，在当事考生持续维权后，招录单位把递补录取也作废了，直接取消招录，把招录变成了一场闹剧。

另外值得关注的是，华商报大风新闻记者到桃山区人社局时，工作人员反问记者：你关注这个问题是什么意思？

5月经济数据陆续出炉，三驾马车涨跌互现。以旧换新力度退坡，透支效应继续显现，叠加国际金价下跌、房地产持续低迷，5月社会消费品零售总额同比下降0.6%，是2023年以来首次为负。从更能体现趋势的季调后环比看，5月社零下降0.38%，连续三个月为负，说明春节假期过后消费增长持续乏力。商品零售连续两月下降，5月降幅扩大至0.7%，餐饮收入增速放缓幅度更大，服务消费表现仍然好于商品消费。

国家统计局发言人解读称，消费市场稳定运行，提质升级的态势没有改变。随着中国发展阶段变化，消费场景日益丰富，服务消费需求加速释放，日益成为消费增长的重要力量，这种变化是经济发展规律所决定的，也是消费升级的重要体现。对于5月商品零售额下降，发言人称，主要原因还是由于去年同期大规模以旧换新和618大促导致基数比较高，也有部分地区高温多雨，影响居民线下消费。而随着消费理念转变，居民对消费品的关注更多地从“有没有”向“好不好”转变，品质消费的需求不断扩大。不过他也承认，居民消费能力和意愿还有待进一步增强，一些领域的市场供给也还不能完全满足消费升级的需要。对此，要深入实施提振消费专项行动，多措并举，促进居民就业增收，不断创新消费场景，优化消费环境，更好地释放消费潜力，改善人民生活。

出口方面，由于全球AI投资热潮继续带动，5月出口再次好于市场预期。以美元计的出口金额3767.8亿，同比增长19.4%；进口2713.5亿，增长27.4%；当月贸易顺差1054.3亿美元，创历史同期最高水平。以人民币计，5月出口进口分别增长13.8%和21.5%，增速均较上月进一步提升。从出口上面看，与AI关系密切的集成电路和自动数据处理设备出口额增长最快。不过集成电路5月当月和前5月出口量同比仅增长2.1%和8.7%，表明对出口额的带动主要是芯片涨价。中国对集成电路、自动数据处理设备进口额也较大，5月同比分别增长68%和80.1%。相比电子等AI相关行业出口强劲，服装、家电、玩具等反映海外消费需求的商品出口持平或走弱。

投资表现也不及预期。1-5月固定资产投资同比下降4.1%，降幅较前四个月扩大2.5个百分点。房地产仍是最大拖累，下降16.2%，5月当月更是下降24.4%。不过扣除房地产开发，前五个月投资同比仍下降1.2%，是2024年有数据以来最低。从季调后环比来看，5月投资下降1.91%，连续三个月为负。前五个月的制造业投资增速在年内首次转负，或与行业产能利用率较低、反内卷持续推进有关，而AI、新能源相关产业投资增速较快。民间投资降幅扩大到7.1%，扣除房地产开发仍下降3.5%；国有控股投资增速也转负，下降0.4%。

统计局发言人表示，对于投资增速变化，需要全面客观辩证地看，不仅要看总量规模变化，更要注重结构质量效益。一到五月固投降幅有所扩大，有局部地区高温多雨的影响，也是新旧发展动能转换、投资由总量扩张向质量提升转变的客观反映。尽管投资增速下降，但在政策持续发力、创新引领增强、民生保障加力这些因素带动下，投资结构持续优化。

而国务院发展研究中心原副主任刘世锦日前表示，中国制造业和产业链具有全球竞争优势，而较多产业现在产能过剩问题突出，部分群体需求得不到满足，供强需弱是一种体制性和结构性现象，背后是国民收入使用结构中的高储蓄低消费。从全球范围来看，无论从发展阶段看，还是从收入水平来讲，中国储蓄率是高高在上，不是一般的高。他指出，过去相当长时间内，尽管中国消费占GDP的比重低于全球平均水平大概20个百分点，但经济看起来还不错，主要是因为房地产和基建高速增长，掩盖了消费占比较低的结构性偏差。2022年以后房地产基建下来了，这个结构性偏差就水落石出，成为终端需求的卡脖子环节。中国经济最近几年的问题是终端需求相对收缩，进一步导致宏观经济减速、产能过剩加剧、名义增速低于实际增速等。但同时投资尤其是生产性投资过多，导致产能利用率下降；产能利用率过低，投资回报过低，进而压制投资意愿，这就是当前投资滑坡的主要原因。他认为当务之急是要恢复投资活力，恢复投资正增长，而如果没有足够的终端需求，又会加剧供需矛盾。他建议降低企业储蓄率，推进税收改革和社保改革，社保改革有助于提高全社会的终端需求水平。
