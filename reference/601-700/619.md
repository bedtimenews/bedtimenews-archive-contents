# 

大家好，我是小黛，欢迎来到第619期参考信息。

上期讲新型毒品和未列管成瘾性物质在国内蔓延，有观众呼吁国家能不能对槟榔加强监管。广东市监局近日答复人大代表关于加强槟榔及其制品销售监管的建议时称，将系统论证将槟榔划为特殊管控品类的可行性，在条件成熟后启动立项。

小槟榔在两广、湖南、海南等地非常流行。槟榔含有槟榔碱、多酚等多类致癌物，可导致隐匿口腔癌。2003年，槟榔就被世卫组织认定为一类致癌物。2020年，市监总局从食品生产许可目录中删除槟榔，2021年，广告宣传被叫停。理论上，槟榔唯一合法的市场定位是作为中药材使用，一般是煎服而非直接咀嚼，但销售渠道始终未受限制，国家层面也没有监管法律法规，除了厦门等个别明令禁售的城市，其他地区能在商超轻易买到。厦门早在1996年就立法禁止生产、销售和食用槟榔。

近年来，多地人大代表呼吁加强槟榔销售监管。2025年，济南历城区人大代表提交《进一步加强对槟榔及槟榔制品销售和宣传监管的建议》；浙江舟山市人大代表提出禁止售卖槟榔制品的议案，但没有实质性回应。而槟榔产业发达的湖南和海南，代表委员更关注相关立法。2022年，农业部答复政协提案时表示，支持海南利用自贸港立法权和地方立法权，借鉴烟草监管经验，从特色产品、嗜好品管理角度，加快推进槟榔产业健康发展地方立法，试点将槟榔作为地方特色农产品规范管理。2023年，湖南人大代表建议推动槟榔地方立法前期论证，省司法厅回应称，当前社会对通过地方立法确立槟榔地方特色产品定位存在诸多争议，建议省市监局密切关注海南动作。今年海南两会上，琼海代表团提出，2021年槟榔监管政策调整后，槟榔产业陷入身份不明、监管缺失、准入无序的困局，建议海南省运用自贸港法规制定权，将《槟榔产业发展与管理条例》纳入今年的立法规划，同步推动湖南省将槟榔制品管理办法列入年度立法计划，实现琼湘监管协同，立法需明确槟榔地方特色农产品与传统药用植物双重属性。

欧美国家将槟榔按有害物质处置，美国甚至禁止跨州贸易，监管政策主要基于健康风险。而我国槟榔产业涉及数百万农民生计，政策就得在健康与产业间寻求平衡。去年1月，湖南42岁博主雨虹因为口腔癌离世，她嚼槟榔10年，经常口腔溃疡，后被确诊颊癌割去右脸，劝解网友珍惜生命远离槟榔。口腔癌在2020年已经位列湖南男性癌症发病率第6位，而槟榔消费在2010年前后快速扩张，癌症发生通常有10到20年的滞后期，很多人的损伤正在累积，未来10年病例可能显著上升。

心机商标终于有法管了。商标法施行40多年后迎来首次全面修订，日前在人大常委会通过，明年起施行，修订后的商标法将严格规制心机商标。去年以来，在商品外包装上，以商标与特定文字、图形等结合，对消费者进行误导的案例时有曝光，引发大众持续声讨。例如白象多半袋，并不意味着这袋方便面真比其他品牌多半袋；一品牛肉干不是牛肉，而是一品牛排肉干；德子土鸡、山里来的土鸡蛋、壹号土猪肉都是同样的套路，德子土、山里来的土、壹号土是商标。千禾零添加酱油就更有名了。

今年3月以来，今麦郎手打挂面和陈克明手擀挂面也被曝不是手工制作，而是使用“手打”或者陈克明“手擀”商标的机器生产挂面。今麦郎的外包装上，手打挂面四个字格外突出，不怎么起眼的是，手字右上方有一个标识：圈R。根据商标法实施条例，使用注册商标时，可在包装上标明“注册商标”或者圈R等注册标记，但不是所有消费者都明白圈R标记的意义。相比之下，手打挂面四个汉字连贯的排版与表意却直白浅显，让许多消费者理解为手工制作的挂面。事件曝光后，今麦郎董事长表示，不再使用2006年注册的手打商标，停产所有带有手打商标的产品；陈克明也全面停产停售所有带有手擀相关表述的产品。

全国人大常委会法工委发言人、研究室主任黄海华早前表示，有的企业在商标注册、使用上煞费苦心，将商标作为误导消费者的“套路工具”，“心机商标”一词充分表明了消费者的负面评价，这一行为严重扰乱商标管理秩序，损害消费者合法权益。针对使用心机商标等误导公众的方式使用注册商标的，修订后的商标法明确，任何单位或者个人有权向负责商标管理、执法的部门投诉举报，由负责商标执法的部门责令限期改正、处罚款；逾期不改正的，由国务院商标管理部门撤销注册商标。商标注册申请人明知标志带有欺骗性，容易使公众对商品的质量、工艺、原料等特点或者产地产生误认的，仍作为商标申请注册，造成不良影响的，承担法律责任。从2023年到今年4月，国家知识产权局已经驳回127.3万件易误导消费者的心机商标申请；截至4月，3351件已注册商标因为存在严重误导被宣告无效。

当法学遇上玄学，要怎么判？其他一名寺庙住持因为做法事被控诈骗，开庭后出现转折，检方近日以证据不足为由撤诉，获得法院准许。卷入案件的住持，法名释智觉，俗名张朝明，现年55岁，湖南醴陵人，20岁在四川昭觉寺出家，2022年到西安禅经寺担任住持。据来自北京的事主陈述，其女儿华华长期抑郁焦虑，2023年，15岁的华华休学在家，就医没有改善。当年6月，事主经人介绍认识释智觉，释智觉到海淀探望华华，并告知事主，梦见华华被一个穿红衣服、皮肤黑的女鬼缠身，做火供法事可以驱除。7月，事主带华华到西安禅经寺，花了3万，由释智觉主持做了火供，还以放生随喜、供养师父、点灯随喜的名义，多次转账给释智觉1.4万。华华多次到禅经寺挂单修行，情况一度好转。但2024年6月，禅经寺弟子以安全为由收走华华私藏的刀片，双方发生争执，华华的情绪再次转差，事主由此怀疑法事效果，随后在海淀报警，控告释智觉利用为其女儿治疗抑郁的迫切心理，对其进行洗脑和诱骗。释智觉很快因为涉嫌诈骗被刑拘、批捕、公诉。

去年10月，案件两次开庭，释智觉辩称无罪，真诚相信做火供可以缓解华华的精神状态，但没有承诺过能够治愈抑郁。辩护律师表示，公诉机关未能也无法证明释智觉梦到被害人的女儿被女鬼缠身是虚构事实，将梦境视为预言并进行阐释，是佛教的常见认识与表达行为，要区分宗教信仰化与体系表达和刑法所称的虚构事实，刑法不能对个人内心的宗教体验进行真伪判断。另一焦点是法事费用的性质。公诉人认为，释智觉虚构火供作用，以骗取高额的服务费，具有非法占有他人钱财的故意。释智觉供述，收到的4.4万捐赠大多用于日常维护支出和赡养年事已高的老和尚。律师认为，以做法事和供养的名义接受个人和社会捐赠，属于合法宗教活动，且具有明码标价，被害人作为具有完全民事行为能力人，对法事费用3万并没有提出异议，也没有任何证据指向随喜捐赠款被释智觉用于个人挥霍。

今年2月，被关了一年半的释智觉取保候审回到西安。得知撤诉后，他表示，通过这个案子，希望国家保障宗教人员的合法权益，保证宗教法事活动的合法地位。辩护律师表示，本案中侦查机关和检察院将宗教领域的自愿捐赠行为错误地拔高为刑事犯罪，将僧人正常的宗教活动和信仰的宗教体验定性为诈骗，不仅违背刑法谦抑性原则，更不当干预了公民宗教信仰自由。本案的意义在于理清了司法与宗教的边界。

大学里一股新玄学在兴起：卷竞赛。澎湃新闻今天刊发长篇报道《“卷”竞赛的大学生》。热衷参加竞赛的大三学生李杰不喜欢把时间浪费在无意义的事情上，一些同学喜欢玩游戏，他几乎不玩。上大学前，他想象过能够认识志同道合的朋友，让自己眼界变得更广阔。上大学后，他也感到焦虑，尤其是在网上看到顶尖高校的学生参加各种竞赛和实习，他觉得自己也应该这么做。但他有时会在有意义和能加分之间纠结，他想参加的比赛，可能因为不在学校的综测加分认可范围内，得不到老师的支持。综测分数常作为评优、评奖学金、保研的重要依据。教育部认可的大学生学科竞赛有84项，学校也会制定自己的竞赛管理办法与加分清单。

大二的周湘已经参加了十多项竞赛，她想多参加一些，多赌一赌，今年要二战中国机器人及人工智能大赛，因为上次参赛队友失误，她对全国三等奖的结果不满意。竞赛内容是通过遥控器操控让机器车抓物体，以及让自动机器人抱起物体后沿着tag码走过去。按照周湘的说法，没有什么智能的算法，赛前她只学了一个星期。周湘会把竞赛经历更新在简历里，她想争取保研，因为绩点很难拉开距离，身边不少同学在卷竞赛加分。

大学生学科竞赛旨在培养学生的实践能力、创新和合作精神，是筛选培养人才的重要途径，但创新和实践越来越让位于加分等功利性需求。东部沿海一所高校教师陈文介绍，现在高校追求破五唯，对教师的考评不仅依据论文和研究项目，还考察其他成果，老师想尽快晋升或者竞争一些人才称号，会在其他方面投入精力，包括指导学生参加竞赛并获奖。陈文也想鼓励学生去参加一些活动和竞赛，但他发现某项竞赛不在综测加分清单里，就几乎没有学生会报名，也是一种很尴尬的境地。他同时觉得可惜，因为许多学生需要处理的任务太多了，没办法投入太多精力在某一项比赛中，创新也好，创业也好，都只能浅尝辄止，这可能是一种锻炼，但很难有实际创新的成果。

卷竞赛还改变了学生的人际关系。周湘和同学平常关系很好，但是涉及评奖评优，她还是会担心因此失和。她听说有同学为了比赛加分，投靠其他学院的团队。她自己则考虑，作为特色班学生，同班同学综合素质更强，但得奖后，队内名次的排列会有竞争，所以她不能轻易跟同班同学组队。不过参加几次比赛后，她感觉非同班同学素质没有那么高，于是也变得能接受跟同班同学组队了。李杰则表示，自己已经很久没跟活人说过话了。之前一起玩的朋友要考研，他没有其他朋友，这也让他觉得很无聊。

正确政绩观教育正如火如荼。中央层面树立和践行正确政绩观学习教育工作专班日前通报了三起政绩观偏差典型案例。广西南宁利用国企自有资金循环空转，虚增财政收入。早前有15宗土地被无偿划拨给三家市属国企，用于公益性项目和基础设施建设。2024年，南宁直接修改国有建设用地划拨决定书，将原本为0元的划拨价款修改为84万至5亿不等，再向三家企业收取划拨价款。财政部门收到企业用自有资金上缴的划拨价款，并计入财政收入，再以征地补偿名义返还，如此循环空转，其中一宗土地最多达18次。通过这种方式，共虚增财政收入28.3亿。甘肃酒泉新城区骗取超长期特别国债资金建设景观工程，不仅未实现目标，反而严重妨碍泄洪。浙江杭州萧山区利用两家融资平台违规新增隐债，在债务未清零的情况下虚假退出。这三起案例都是单位的，月中还通报了五起个人案例。

比如河北邯郸原副市长任华山，当廊坊文安县委书记时，为追求个人政绩，未经深入调研，明知项目资金不足、“三保”等支出难以足额保障，盲目同时启动多个城中村征迁项目，部分安置房未能如期完工，村民无法及时回迁安置，工人工资被拖欠。为打造城南花海人文网红景点，明知项目违法占地、不符合规划，仍然大力推动要求施工。四川攀枝花市原副市长龙勇，任西区区长、书记期间，未组织调研，未经专家论证，未充分听取班子其他成员意见，就决定发展钒钛铸造、钒钛新材料、康复辅具等产业集群，并发放大量补助资金，部分项目不符合国家政策，建成即停产。还在招商引资中急功近利，重签约、轻落实，牵头组织招商活动数十场，签约项目协议投资额数十亿，实际落地不足7%。广西来宾市兴宾区原书记杨添才，落实中央化债部署打折扣、搞变通，致使政府债务大幅增长，以及未充分考虑财政承受能力，明知用地审批等手续尚未办理，仍主导推动建设城南新区红水河滨江公园项目。

导致82人死亡的特大矿难发生一个月有余，山西沁源三任县委书记相继倒台。矿难发生11天后，6月2日，时任书记赵永进任上落马，他原本在4月干部任前公示中，拟提名为副市长人选。24日，已在2017年卸任的原书记李丁夫主动投案。27日，长治市委常委、原副市长王玉圣被查，69岁的王玉圣是李丁夫的前任，2001年起任沁源书记长达10年。在李丁夫之后和赵永进之前，还有一个金所军，任期3年多，已在2023年被查。至此，2001年以来，沁源连续4任书记全部落马。

上周，国防科工局副局长卞志刚、中央社会工作部副部长贺志亮任上被查。卞志刚在4名副局长中排名第二，是张建华之后又一名被查的国防科工局副局长。他是南京理工1985级校友，长期在系统内工作，历任系统三司司长、计划司司长、局总工程师等，2024年2月升任国防科工局副局长，兼国家航天局副局长。近年来，工信系统特别是国防科工系统已有24名要员落马或者被撤职，包括马兴瑞。贺志亮在4名中央社工部副部长中排名最末，现年55岁。1995年从内蒙古农牧学院农学专业毕业后，选调回乡，从农科技术员起步，当到内蒙古宣传部副部长、文旅厅首任厅长。2019年转任吉林，后任副省长兼公安厅长，去年1月进京，出任中央社工部副部长，直至被查。

24日，政协全国委员会常务委员会闭幕，近期被查的湖北原省长王晓东、北京市政协主席魏小东、河北省数据和政务服务局局长侯贵松，均被撤销政协委员。26日，人大常委会公告终止15名代表资格，包括已落马的马兴瑞、重庆原副书记胡衡华，和3名上将、3名中将，分别经装备发展部、西部战区、空军、东部战区、陆军及网络空间部队军人代表大会罢免。此外，金融监管总局原局长李云泽也被罢免代表，简历4月已从总局官网撤下。
