# 

大家好，我是小黛，欢迎来到第624期参考信息。

二季度和上半年经济数据集中出炉。受美伊冲突和结构转型等影响，当前经济下行压力加大：上半年按不变价格计算的GDP实际增速为同比增长4.7%，其中二季度同比增长4.3%，低于一季度0.7个百分点。不过，在国际油价、AI产业链价格上涨的带动下，二季度以现价计算的名义增速为5.9%，结束了连续12个季度的GDP平减指数为负。从环比增速看，二季度增长0.9%，低于上季度0.4个百分点，2024年以来首次低于1%，显示经济增长动能趋弱。国家统计局也表示，外部不稳定、不确定因素较多，国内供强需弱矛盾突出，经济向好基础还需巩固。

就业方面，上半年城镇调查失业率均值为5.2%，其中6月为5%，比上月下降0.1个百分点。同样在部分价格改善的带动下，居民人均可支配收入同比名义增长5.2%，达到22981元，扣除价格因素实际增长4.2%，仍低于经济增速；中位数为19036元，是平均数的82.8%，中位数的增速低于平均数0.5个百分点，说明中低收入人群增长偏慢。带动上半年收入增速加快的主要是工资性收入和转移净收入，人均财产净收入仍是主要拖累因素——尽管二季度股市活跃，但上半年人均财产净收入同比仅增长1.1%，低于一季度0.5个百分点，显示房地产市场的拖累仍在持续。

人均可支配收入数据与居民的微观感受存在差异。国家统计局承认，人均可支配收入指标存在一定局限性，无法反映不同行业职业、不同文化程度、不同家庭规模等群体间的收入差异，建议同时关注分城乡、分地区的人均可支配收入、收入中位数和收入五等份等数据。

居民消费意愿仍然偏低。上半年居民人均消费支出比上年名义仅增长3.7%，扣除价格因素实际增长2.7%。以居民人均消费支出除以人均可支配收入计算居民消费倾向，上半年为64.56%，低于上年同期0.96个百分点，自2013年有数据以来仅高于疫情较重的2020和2022年同期，显示居民存在不愿意消费、不敢消费的倾向。

不过，受618电商大促、端午假期错位带来的基数走低等因素拉动，6月消费有所回暖：社会消费品零售总额同比增长1%，上个月则是近三年多来的低点，为-0.6%，6月回升了1.6个百分点，为近三个月来最高。从更能体现趋势的季调后环比看，6月社零环比增长0.38%，结束两连降，创近一年来新高，显示当月消费内在动能较强。

6月的出口和进口额继续高速增长。以美元计的出口额4123.9亿美元，同比增长27%，创2021年10月以来新高；进口金额2867.6亿美元，同比增长36%，是2021年7月以来单月最高增幅，主要是受与AI关系密切的集成电路和自动数据处理设备涨价影响。上半年电子元件、电脑零部件等产品出口均两位数增长，合计拉动出口增长6.9个百分点。值得注意的是，集成电路的出口量在6月同比微降0.5%，上半年累计同比增长7%，远低于同期出口额96.1%的增速。

生产端上，尽管新动能行业、部分反内卷重点行业产能利用情况向好，但二季度工业总体产能利用率降至73%，创下6年以来最低值，仅高于新冠疫情爆发时2020年一季度的67.3%，与上一轮供给侧改革2016年同期的73.1%接近。产能利用率下降主要受煤炭行业以及石化产业链相关中游行业的影响。广发证券研报称，电气机械行业产能利用率走低趋势较为明显，二季度落至2020年以来低点，背后可能是新能源行业供求关系有待改善，反内卷仍需继续推进。

投资方面的走弱幅度超出预期。上半年全国固定资产投资同比下降5.7%，增速比前五个月低1.6个百分点；6月当月固投同比下降11.2%，降幅较五月收窄；从更能体现趋势的季调后环比看，6月下降0.37%，降幅为近四个月来最小。三大类投资不同程度走弱，前五个月同比均已转负：上半年制造业投资累计同比降幅扩大至1.2%，基础设施投资由增长0.6%转为下降1.1%，年内首次转负；房地产开发投资降幅扩大至18%。说明除了房地产持续调整，传统基建和制造业投资也在放缓。不过，上半年集成电路制造、电子专用材料制造、锂离子电池制造投资分别大增8.8%、10%和24.4%，也是一种K型分化。此外，上半年民间投资同比降幅扩大至8.5%，持续低于总体水平；扣除房地产开发的民间投资下降4.9%；国有控股投资同比增速已在1-5月转为下降，上半年累计降幅扩大至2.3%，不过仍高于民间投资增速。

日前，中央层面整治形式主义为基层减负专项工作机制办公室再通报三起典型，其中一起是福建漳州、南平纠治统计造假不力。2025年，漳州、南平一些县市区以指令报数、代填代报、包装虚假项目等手段干预统计工作：有的将“指导数”装入信封点对点下发，有的制作虚假审批文件为虚假项目入库“开绿灯”，有的直接代填代报企业数据。今年上半年，在国家统计局反馈龙海区、建瓯市、顺昌县统计造假后，漳州、南平仍将其2025年考评结果评定为优秀。在中央对纠治统计造假做出部署后，漳州长泰区1-5月规上工业企业总产值失实率仍达28.28%，有的半停产企业被要求报送总产值不能低于上年同期，有的企业在被干预后虚报总产值。

既然是典型，那说明不是个案。半月谈去年就指出，近年来一些地方和部门出现新型隐形统计数据造假，比如以会议等形式调度数据，相互之间跑数要数，用补贴等名义购买数据等等，相对隐蔽、不易被发现。有的不仅强势干预统计，还阻碍监督检查。比如2019年云南红河州在全国第四次经济普查中，州县职能部门和乡镇政府出具虚假批文、代填代报，授意指使强令普查对象提供虚假资料；上级检查期间，部分单位和领导还解散QQ工作群、毁弃证明资料，有的县领导还要求被查单位自行承担责任，不得指认县委县政府。

统计数据关乎官员个人荣辱升迁，也与本地资源分配紧密挂钩，顶风作案是否能带来好处？统计法规定，不得明示暗示下级单位及其人员、统计调查对象填报虚假统计数据；党纪处分条例也规定，对统计造假和对统计造假失察，最严重可开除党籍。可见，造假有成本，但还是有人蠢蠢欲动，原因在于不少地方追责问责宽松软。半月谈就提到，有的县区造假责任人被提拔重用，还有造假责任人考核被评为优秀。法治日报2019年曾报道，有统计局工作人员及不少学者指出，极少有人因为插手统计和数据弄虚作假丢官，对政府负责人则只是诫勉谈话或行政记过，连开除都很少见到，可见造假风险小于收益。这次通报也指出，有的地方纠治统计造假不力，只考不核、不惩反奖，导致造假问题边改边犯、屡禁不绝。

河南渑池县法院的一纸退案决定书引发关注。案涉生产、销售有毒有害食品罪，法院一审判了两名被告十几年；二审被发回重审时，则指公安机关有远洋捕捞、趋利执法之嫌。简单介绍下案情：2023年10月，渑池的冯先生在网上花了198元，买了一盒男性保健品澳洲牡蛎肽压片糖果，自称吃了一粒就头疼呕吐，怀疑是假药，到派出所报案。有两点比较蹊跷：他既不去求医，也不向商家索赔；他在派出所当过临时工。两个月后，远在广东、重庆的五名当事人被渑池警方跨省带走。去年8月，渑池法院作出一审有罪判决，五名被告被判刑，两人刑期超过10年，罚金合计636万，案件一度引发关注。二审的三门峡中院以部分事实不清、证据不足、程序不当为由发回重审。渑池法院重组合议庭，认为这起生产地在聊城、销售地在珠海、面向全国的案件，从结果或关联上看，渑池县对本案的管辖权都值得商榷，且被害人报案与常情不符，被告人家属提出被害人系公安机关临聘人员报假案等。经核实，报案人2017-2018年在派出所干过临时工。结合前述管辖与通常规定不符，不排除公安机关有远洋捕捞、趋利执法之嫌。7月10日，渑池检察院承办检察官称，已决定将此案退回公安机关处理。

南方都市报评论：法院直接退案本就不多见，退案决定书明示存在趋利执法嫌疑的更是稀有。本案中，渑池法院的退案理由没有局限在退回检察院的层面，而是有更进一步的司法说理和程序刺破，将公安机关同样管辖权不适格的事实予以明确的否定性评价，不遮不掩，称得上果断干脆。根据公安部门规定，犯罪地涉及多个省份的涉企案件，由主要犯罪地公安机关管辖，并层报省级公安机关业务主管部门备案。渑池法院退案理由直指本案未经省级公安机关指定，且渑池县公安局的侦查也与管辖权相关法律规定不符，故本案侦查机关缺乏管辖权。一份普通退案决定的字里行间，有点出案件不寻常之处的勇气，有直白说出程序乖谬的干脆，于具体法治而言难能可贵。现在痛打远洋捕捞、狙击趋利执法，在理论上已经不存在任何障碍，但到底会在程序的哪一个端口触发制约程序，依然考验不同司法环节的专业坚持：是将错就错还是戳破问题，关键看能否深刻理解刑诉法对各部门互相配合、互相监督的制度初衷。

最后关注癌症趋势。我国正在重塑全球癌症格局：以世界17%的人口贡献了25%的癌症负担，每年新增病例超过500万。中国医学科学院肿瘤医院、国家癌症中心科研人员近期在国际医学期刊《自然评论临床肿瘤学》发表综述研究，题为《中国癌症负担与控制：现状、趋势与挑战》。2022年全球估计有1996万例新发癌症病例和974万例相关死亡，中国分别为482万和257万，都占约四分之一。因为快速老龄化和诊断能力提升，中国新发癌症诊断数从2010年的309万增加到2024年的515万，相关死亡从196万增加到258万，约占2024年死亡人数的24%。2024年中国癌症年龄标准化发病率为每10万人207.7例，略高于2022年全球平均的196.9例；年龄标准化死亡率为每10万人90.9例，与2022年全球平均的91.7例相近。一些在发达国家常见的，如肺癌、结直肠癌、前列腺癌、甲状腺癌、乳腺癌和宫颈癌，在中国发病率上升；中国历史上常见的，如食管癌、胃癌和肝癌发病率大幅下降。

中国癌症负担广泛且高度多样化。2024年发病率前10为肺癌、甲状腺癌、结直肠癌、乳腺癌、肝癌、胃癌、食管癌、前列腺癌、宫颈癌、胰腺癌，每年新发病例均超过12万例；死亡率前10的是肺癌、肝癌、结直肠癌、胃癌、食管癌、胰腺癌、乳腺癌、脑癌、前列腺癌、白血病，每年每种导致死亡均超过5万例。肺癌仍然是头号杀手，2024年新发病例约118万，死亡超过74万。男性最常见的五种癌症是肺癌、结直肠癌、肝癌、胃癌和前列腺癌；女性是肺癌、甲状腺癌、乳腺癌、结直肠癌和宫颈癌。

中国癌症早期诊断仍存在巨大差距，直接影响患者生存结果。美国2015-2021年诊断的癌症患者5年相对生存率为70%，显著高于中国2019-2021年诊断患者的43.7%。除了食管癌、脑癌和肺癌，几乎所有癌种在美国的相对生存率均高于中国。中国正处于前所未有的老龄化时代，预计到2050年，新发癌症诊断数为800万到1000万例，相关死亡为320万到400万例。研究人员提醒，中国未来将面临巨大癌症负担，对个人、家庭和社会及政府和医疗体系构成各种挑战。

世卫组织与国际癌症研究机构近日联合发布首份全面分析全球癌症预防和控制进展的报告：全球每5人就有1人一生中会罹患癌症，92%的人一生中至少会因自己或者亲近的家人患癌而受到影响一次。癌症是仅次于心血管疾病的全球第二大死因，2024年约有2060万例新发病例，约1000万人死亡。亚洲癌症负担最沉重，占全球病例的50.7%、死亡病例的56.5%，与庞大的人口基数相符；欧洲尽管人口仅占世界的9%，却占全球癌症病例的21%和死亡病例的20%。肺癌仍是头号杀手，乳腺癌和结直肠癌同样带来较大的全球疾病负担；约51%的新发病例发生在65岁及以上人群，随着全球人口增长和老龄化，绝对数量还将继续增加。报告提醒，若不采取更有力行动，到2050年癌症预计将成为过早死亡的首要原因，并带来沉重的经济负担。

报告最新证据显示，近4成癌症病例与可预防或者可改变的危险因素有关，包括烟草使用和二手烟暴露，饮酒、HPV、乙型肝炎病毒等致癌感染，超重和肥胖、身体活动不足、空气污染以及部分环境和职业暴露。包括中国在内的西太平洋区域，吸烟与18.5%的癌症新发病例有关，感染与12.4%的新发病例有关，空气污染与4.3%的新发病例有关。报告提醒，人们能否远离烟草和酒精危害、是否及时接种疫苗、能否获得规范的筛查和基层卫生服务，以及是否暴露于空气污染或职业致癌因素，这些都不完全取决于个人，也需要通过政策和立法建立支持健康生活方式和健康选择的公共环境，并提供公平可及的医疗卫生服务。

报告指出，许多被证实有效的癌症防控措施尚未得到充分、持续和公平的实施：全球仅27%的国家癌症控制计划拥有专门的筹资机制，39%的国家在全民健康覆盖服务包中纳入了基本癌症服务，26%的计划提及本国基本药物目录。报告还揭示了在预防、诊断、治疗和支持性护理方面日益扩大的不平等：高收入国家的乳腺癌和儿童癌症患者五年生存率超过85%，而在许多低收入国家低于30%。许多人在接受治疗之前就已经面临转诊不及时、诊断能力不足和专科服务短缺等障碍，还有一些患者则因为医疗服务或药品不可及或费用难以负担而中断治疗。
