# 

大家好，我是小黛，欢迎来到第631期参考信息。

首先关注年中的最高层会议。上半年虽然GDP同比4.7%的增速还在目标区间内，但是二季度当季增速跌出了目标区间，并且供强需弱持续，结构分化加剧，市场和社会对K型分化的讨论增多，产业、企业、区域、收入分配都呈现出典型的分化态势。7月30日的最高层会议提出，要高度重视经济运行中的困难挑战，加快推动新旧动能转换，及时谋划出台务实管用的增量政策，加大逆周期调节力度，加力扩大内需、优化供给，切实保障和改善民生。

宏观政策上，12月会议已经定调，要更加积极有为，增强政策前瞻性、针对性、协同性。4月会议进一步要求用好用足宏观政策。此次会议指出，做好下半年经济工作，宏观政策要发力提效，既要充分发挥各项存量政策效能，也要及时谋划出台务实实用的增量政策。务实实用的增量政策是什么，发改委也语焉不详，市场各自按需解读，多是认为围绕消费、就业、重大项目、基建实物量等做好研判储备。财政政策方面，会议要求加快财政支出和债券资金使用进度，有力推进“两重”建设和“两新”工作。货币政策方面，相较于4月会议增强前瞻性、灵活性、针对性的表态，本次重点提出综合运用并适时调整货币政策工具，优化实施财政金融协同促内需政策。与4月会议相比，此次增加一节专门谈及营造公平有序的市场竞争环境，除了重申制定实施全国统一大市场建设条例，继续综合整治内卷式竞争，还在解决企业账款拖欠问题前首次增加了常态化要求。有效扩大内需仍是下半年的首要任务。在提振消费上，会议提出适应不同群体消费需求，扩大优质供给，挖掘服务消费潜力。

关于加快现代化产业体系建设，除了积极推动前沿技术突破和未来产业发展，也要求持续推动传统产业改造升级。稳投资方面，六张网是重点。4月会议要求加强六张网规划建设，这次会议变成扎实推进。六张网是水网、新型电网、算力网、新一代通信网、城市地下管网、物流网，今年相关领域建设投资规模将超过7万亿。此前7月20日，国常会就听取了对六张网规划建设督查情况汇报，31日国常会又听取了新型电网、物流网建设情况汇报。市场预计，六张网将成为下半年扩大有效投资的主要载体。

昨天国常会还决定核准四个核电项目，今年核电新项目审批开闸，四个项目共八台机组，分别是浙江金七门核电二期、广东太平岭核电三期、辽宁庄河核电一期、山东莱阳核电一期，各两台机组。其中庄河、莱阳项目都是新的核电厂址，金七门、太平岭项目将有升级后的华龙一号2.0版落地。核电历来是扩大有效投资的重要拉力，四个新项目总投资将超过1700亿，三大核电央企中，中核、中广核和国家电投均有斩获，我国在运在建核电规模持续领跑全球。对于广东、山东、浙江等沿海经济大省来说，核电对经济与用能的支撑意义尤为显著。国内核电审批2019年正式重启，2022年加速之后，每年核准机组都超过10台。值得注意的是，内陆核电依然遥遥无期。2011年日本福岛核事故后，国内核电也一度暂停，直到2012年下半年才进入半开禁状态，准入门槛也提高了。近年来，新上的核电项目都在沿海，福岛核事故前已经开展前期工作的湖南桃花江、江西彭泽、湖北大畈三大内陆核电站都已沉寂。

核电被认为是安全高效清洁的能源，为同时解决环境和气候变化问题提供了现实选项。如今可再生能源在电网的比例提高，但带来调节和消纳压力，核电则可以提供基荷支撑与有限调峰。而全球变暖出了一个新难题。匈牙利和罗马尼亚7月29日和30日分别暂停了一座核反应堆运行，原因是多瑙河水位由于热浪、降雨减少而降至历史低位，难以保障冷却水供应。再之前，也是因为天气炎热，法国6月22日暂停了一座反应堆运行，并降低两座反应堆输出功率。按规定，核电站在气温过高时将限制排放冷却水以保护河流生态。26日，欧洲现役最古老核电站瑞士贝兹瑙核电站暂停运行，同样是因为高温天气导致河水温度过高。全球核电机组一半以上建在内陆，法国内陆核电占比约七成，美国约六成。前些年讨论重启内陆核电时，中国核能行业协会表示，内陆核电厂的放射性液体流出物排放要求比沿海核电厂更严格，某长江沿岸核电项目选址还考虑了极不可能发生的三峡水库和丹江口水库的连续垮坝的影响。但如今全球变暖带来的新影响不可不考虑。

最高层会议还提到深化资本市场投融资综合改革，提升资本市场韧性和信心。本周资本市场的最大信心，莫过于国产DRAM龙头长鑫科技登陆科创板，上市首日总市值3.28万亿，超越工行登顶A股市值总榜，7月31日收盘时市值升至3.61万亿，超过腾讯和英特尔。市场津津乐道的，除了近千亿身家的创始人、超十位过亿的高管、人均561万的6760名员工，还有错过这场富贵的碧桂园。2024年底，碧桂园将其持有的1.56%长鑫股权作价20亿转给合肥国资，按上市首日股价，值511亿，一进一出差了490亿，抵得上一家头部房企好几年的利润总和。银行、券商、险企及阿里和小米都大赚了一笔。合肥作为最牛风投城市再度被热议。

长鑫科技2016年成立，在当时产业前景高度不确定的情况下，合肥产投出资约144亿，承担了八成初始投资。上市前五大股东分别是清辉集电、长鑫集成、大基金二期、合肥集鑫和安徽省投，合肥市国资占了三个，加上关联主体合计持股约36.79%，省市两级国资持股约45.45%。各省国资也纷纷来投，广州科集持股0.64%，深圳投控持股0.59%，天津海河基金持股0.32%，青岛朗格持股0.75%，安徽芜湖、江苏无锡、四川国资也现身股东名单。视线再拉高一层，大基金二期出资人名单本身就是半张地方国资地图，上海国盛、武汉光谷金控、成都天府国集，浙江富浙、重庆战新基金、江苏疌泉、北京亦庄、广西投资引导基金等，算下来间接持股长鑫的省市国资超过10个，可以说是国家意志的体现。

其实最牛风投城市是典型的爽文叙事，一些地方只讲合肥股权投资的成功，不讲合肥模式的背景。其实是在赌博。合肥模式崛起，是因为能够承接长三角产业转移。成为最牛风投城市之前，合肥已经和青岛、顺德并列为三大家电产业基地，冰箱、彩电、空调、洗衣机合计产量连续十几年位列全球城市之首。没有这个底子，就没有后来的电子产业，当初引进京东方，就是要为家电企业提供显示器配套。和大多数城市一样，合肥也要靠卖地和举债大搞基建、发展房地产，曾连续多年固投规模超过GDP，是非常典型的投资拉动，有几个单年度卖地收入超过1000亿。风投再厉害，给财政贡献也没法和卖地比。总之，不能只在国资赚钱的时候夸国资，亏损、重复建设时就说是交学费、必要的代价。归根结底，在土地财政到头的今天，国资应该怎么用，与青岛、天津国资在长鑫科技的持股比例相映成趣。

青岛上半年GDP以0.39亿的微弱优势超过天津，暂时成为北方经济第二城，但全年还不保险。从民国到新中国，纺织和烟草都有“上青天”的说法，不过青岛和两个直辖市的差距很大。2000年青岛GDP超越大连、沈阳，晋升北方经济第三城，但是天津凭借直辖市政策优势、雄厚的工业基础与核心港口区位，GDP长期领先青岛30%以上。近十年，分化悄然出现。天津面临传统产业转型升级、新旧动能转换挑战，增长放缓；青岛则紧抓新兴产业与现代服务业，迅速壮大。2015年与天津的差距还在20%以上，2022年已缩小至10%以内，去年进一步缩小至5.6%。从历年数据看，天津四季度爆发力强劲，单季GDP占全年近30%。去年前三季度，青岛一度把差距缩小到42.6亿，但全年又被拉大到979亿。

两个城市各有所长。人口上，天津总量更多，去年常住1363万，青岛1051.55万，但是青岛的增量更大。六普至七普，天津增加了92.78万，青岛135.66万；七普至2025年，天津减少了23.6万，青岛则是增加44.38万。收入上青岛更有吸引力，去年人均可支配收入6.3万，高于天津的5.6万，两地工资性收入分别为3.7万、3.5万，大体相当，但青岛人均经营净收入1.1万，几乎是天津的三倍。去年青岛消费品零售总额6960.7亿，是天津的1.7倍，而十多年前，天津还是北方消费第二城，位列全国十强。外贸方面，青岛2022年超过天津，升至北方第二，青岛港也是北方第一大港，去年吞吐量全球第四，集装箱吞吐量全球第五。工业家底双方各有千秋，但是天津的工业增加值、规上工业企业数量、营收与利润仍高于青岛。财税收入方面，一般公共预算收入和税收分别是青岛的1.7倍、1.8倍。一方面因为直辖市拥有更大的财政自主权，而青岛虽是计划单列市，但依然要向山东上缴；另一方面，天津重化工、装备制造相关行业增值税率更高，税收也更加稳定可观。未来几年，青岛正式晋升北方经济第二城的几率很大，“十五五”目标定在年均增长5%以上，天津则是年均4.5%到5%。不过凭借大学、院所等科创资源，天津仍有机会。

这两个月，韩国股市大起大落，实在太刺激了。38天跌掉了一年GDP，昨天又强力反弹17.91%，创下了最大单日涨幅。资本市场之外，Z世代正面临AI颠覆传统职业阶梯的挑战，越来越多韩国青少年放弃考大学，转而进入半导体职业学校。忠清北道的忠北半导体高中最近成为韩国升学的热门话题，被纽约时报称作“韩国最火高中”。17岁高三学生卢俊植已经拿到三星的录用通知，他说初中时就劝一些同学一起来，但很多人最后选择去读普通高中冲刺大学，不少人现在都后悔了。忠北半导体高中是韩国首所贴合半导体产业需求、专项培育技术人才的职业高中，2010年确定为半导体装备领域产业定制型高中，学生约300人，有六处实训场地，配备晶圆制造、封装等全环节实训设备，仿佛一座微型半导体工厂，学生需穿戴防尘服学习实操精密设备。2010年至今，学校就业率始终在95%以上，每届虽不到100人，但约四分之一能进三星、海力士。想进大厂，需要从高一起保持优异成绩，同时满足学校“青年产业技师”认证要求，包括语言成绩、职业资格证、志愿服务等指标。随着半导体行业热度攀升，校内竞争日趋激烈，关于半导体企业高额绩效奖金的报道更推高了报考热度，过去一年入学咨询增加了三倍以上，连带忠南、大邱、庆州等地的同类学校咨询热度大幅攀升。首尔半导体高中也要明年开学，釜山和龙仁计划2028年开设半导体高中。

今年二季度，韩国大学及以上学历的失业超过48万，创下五年新高，15至29岁青年失业率攀升至7.2%，受AI冲击，初级岗位的竞争预计还会加剧。相比之下，半导体制造这类实操性更强的职业，吸引力不断提升。同时，AI浪潮也促使全球年轻人重新思考，传统四年制大学学历还是通往稳定高薪的途径吗？美国本科及以上学历的失业率达到2.7%，是2015年以来仅低于疫情时期的次高，青少年面临80年来最严峻的暑期就业市场。美国超过60%的高中毕业生仍然选择直接上大学，但Trade School职业学校的入学人数稳步上升，2020-2025年，专注于职业和技工课程的公立两年制学校学生人数增长近20%，学徒制和私立职业学校人数也有所增加。

国内职业教育赛道也在被重新审视。眼下正是中考录取时节，上海和广州一批700分左右的考生没有选择重点高中，却选择了中本贯通赛道，福州部分中本贯通专业的最低录取分数线也在680以上。中本贯通是指中职学校与本科高校协同开展“3+4”七年一体化贯通培养，学生前三年在中职学校单独编班学习，通过转段考核后进入对口高校学习四年，达到毕业条件的获得本科毕业证和学位证。高考的不确定性是许多家庭转向中本贯通的核心原因。从风险收益的角度计算，读普高意味着三年高强度学习，高考一次定乾坤，不确定性极高；而七年中本贯通不用卷高考，本科基本锁定，但风险在于转段考试以及不能换专业。在一些家长和学生看来，搏三年不如稳七年。

广州去年首次试点中本贯通，40个名额6366人报考，今年扩招到318人，9542人报志愿，分数不降反升，录取最低控制线站上了632分，690以上的考生不在少数。708分的何梓汶同学分数最高，他选择了广州市轻工职业学校机电技术应用专业，对接广东轻工职业技术大学机械电子工程技术专业。上海今年中本贯通计划数2756人，扩招411人，却迎来八成专业分数线上涨，有的专业甚至暴涨40分。上海商业会计学校与上海电力大学贯通的信息安全专业，以691.5分蝉联榜首；上海港湾学校与上海海事大学贯通的两个专业首次招生，机械设计制造及其自动化691分，物流工程690分。690分比上海普高录取最低线501分高了近200分，已站在市重点录取线上。来自闵行的小陈同学以707分的成绩被上海港湾学校机械设计制造及其自动化专业录取，另一位692.5分的小王放弃杨浦高中选了物流工程，新生群里最高有715分。

中本贯通为学生提供了一条相对便捷的升本渠道，然而热闹背后有几个现实问题绕不开：职校能不能接住这批高分生？过去中职生源大多是考不上高中的，现在突然来了一群能上重点高中的尖子生，教学节奏、课程深度怎么调整？本科文凭的含金量如何，用人单位认不认？虽然政策上“技能+学历”是趋势，但是市场接受仍需要时间。

好的，本期参考信息就是这些，我们下周一再见。
