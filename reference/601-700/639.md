# 

大家好，我是小黛，欢迎来到第639期参考信息。

这个暑假，一个新词在教育圈和家长中流行起来：“预制娃”。大意是指让孩子在假期里提前把下学期的重难点、习题学透练习，在家完成知识预制，开学后由老师二次加热，再用一轮轮考试检验谁家预制的更好。家长则忙着晒单：成绩拔尖的叫牛娃，成绩平平的叫普娃，还有空心娃，指的是把学习当任务、没有内驱力的孩子。对孩子而言，本应是快乐时光的寒暑假，成了第3学期、第4学期，比上学还累。

催生预制娃的原因，一部分是学校违背国家课程方案和标准，超前超纲教学，还有老师旁敲侧击，更多是家长出于升学焦虑，推着孩子开启假期学业竞速。中国教育报评论，预制娃的本质是学业焦虑下的抢跑。个体层面的抢跑，还会引发连锁的跟风竞速，形成典型的剧场效应。剧场内一旦前排有观众站起来，而未及时受到制止，后排观众也只能被迫起身。

预制娃提前接触了众多知识点，但贪多嚼不烂，对知识的掌握可能只停留在浅层记忆层面，并未吃透背后的逻辑内核与底层原理，会透支孩子的学习兴趣与探索欲望，让他们在课堂正式学习时缺乏新鲜感、好奇心，长此以往可能丧失主动思考、深度探究的能力。这种学习品质的损耗，远比一时的成绩落后更可怕。而且还会加重孩子的心理负担与精神压力，家长之间的攀比可能让孩子深陷害怕落后的焦虑。心理学中有个超限效应，当外界刺激超过个体心理承受的阈值，不仅无法达到预期效果，还会引发抵触、反感等负面心理效应。过早过满超负荷学习，很可能会让孩子产生疲惫、麻木与抵触情绪。

说到底，盲目叠加学习任务、超前灌输知识，是一种违背学习和成长节奏的拔苗助长，不仅难以助力长远发展，反而可能透支成长压力，压制天性与创造力，危害身心健康。尤其是在AI快速发展的当下，知识获取门槛越来越低，依靠刷题、死记硬背超前学习建立的优势越来越难以维系，社会对人才能力结构的关注，更聚焦于独立思考、创新思维、解决现实问题、提出新问题等能力。当然也要看到，一些家长的焦虑并非全然源于个体认知，而是与社会环境密不可分，因此不宜简单苛责家长，更重要的是构建健康的教育生态，培育包容多元的社会环境，从根源上疏解教育焦虑。

国家统计局日前公布，7月不含在校生的16到24岁城镇青年失业率为17.9%，与6月14.9%的年度低点相比上升3个百分点，是去年9月以来新高。7月正值大学生毕业，集中进入劳动力市场，今年毕业生有1270万，比去年增加了48万，再叠加往届未就业、海归及考研考公失利群体，夏季求职期压力显著。

面向应届生的校招已经整体收官。前程无忧发布《2026年校园招聘白皮书》指出，伴随产业结构加速升级，供需两端同步发生结构性变化，应届生择业趋向求稳重质，企业招聘则走向精准求精。今年各层次的毕业生都扩张了，硕士生最为突出，2017到2026年毕业生从52万增至111万，10年增长了113.5%。学历通胀，求职竞争门槛提高，今年23.3%的毕业生没有获得任何面试机会，简历到面试的转化效率也偏低。计划考公考编、当教师、进体制的比例达25.1%，比去年高2.6个百分点；选择企业就业、国内国外求学的比例小幅下降，暂不就业的占比超过一成。

从求职企业类型看，36%想进央国企，稳居榜首；想进政府机关、外资合资企业的分别有21.12%、20.2%；民企意向度由11.3%回升至16.7%。有36%的毕业生意向去一线城市，上海持续稳居榜首，但意向排名前20以外的城市也有25.6%的毕业生想去，较2023届提升6.4个百分点，就业布局趋于均衡。

需求端，企业2020-2025年的校招先扩张后收缩，去年较2022年峰值时已收缩约四成。今年只有不到三成的企业计划增加校招人数，近四分之一企业明确缩减校招，央国企收缩最大，仅12.9%计划扩大校招，32.9%要缩减校招。相较之下，民企的扩招意愿更强，尤其是新能源汽车及零配件等战略性新兴产业名企。今年毕业生期望月薪均值为10213元，较上年小幅上涨。C9毕业生近三年期望月薪均值从13758元增至14659元，预期月薪20K以上的在17%以上，多数毕业生心理预期在8000元左右，显示期望学历。还有一个突出变化是企业校招节奏加速，周期持续缩短，不再采用长线招聘模式，大量使用AI筛选简历，力求快速匹配业务用人需求，传统固定校招节奏彻底重构。

国家又发文件促消费了，这次瞄准的是县域。7月虽然是暑期，但是消费增速放缓，受以旧换新等补贴政策退坡的影响，汽车、家具、体育娱乐类商品零售增速大幅下滑，但暑期旅游和文体休闲等服务消费保持两位数增长。上一期，最高层会议提出要有效扩大内需，适应不同群体消费需求，扩大优质供给，挖掘服务消费潜力。商务部等九部门日前联合出台《关于进一步激发下沉市场活力活跃县域消费的意见》，提出18条举措，主要从供给侧入手，如支持县域消费渠道升级，支持传统百货、老旧购物中心等升级改造，总结运用义乌经验，建设改造与本地特色产业结合的专业市场和集散中心；要求各地规范和优化消防、市场监管等领域审批，不得对连锁企业跨区经营设置显性隐性障碍；支持发展承载地方文化的小店、老字号、作坊式品牌，支持国货潮品下沉县域市场；支持以演出赛事门票延伸消费链条，打造乡村旅游目的地等；以及通过推动就业、鼓励创业来增强县域消费保障能力，鼓励因地制宜建设农村创业园等返乡创业孵化载体，培育更多县域劳务品牌，支持家装家电企业与房企联动营销，满足多孩家庭住房需求等。

近年来，一二线城市消费增长逐步见顶，县域市场成为消费企业挖掘潜力的重要阵地，参与零售企业加速布局第一线城市，不少上市消费企业在招股书中强调下沉市场门店占比这一指标。今年前七个月城镇消费品零售额24.9万亿，同比增长1.1%，乡村为3.8万亿，虽然不到城镇零售额的两成，但是增速比城镇高出了1.3个百分点。麦肯锡预测到2030年，中国个人消费增长来自三线及以下、县乡等下沉市场的占比将达到66%。

政策层也注意到了县域消费潜力。国务院7月出台的《扩大消费“十五五”规划》就提出，加力实施县域商业提质增效行动，壮大县域消费市场。不过县域消费者并非一味偏好低价，消费投资机构黑蚁资本去年在消费者趋势研究报告中指出，县城消费者的消费动机，正从对外在身份符号的追求，转向对内在实用价值与情感陪伴的重视，增长见识成为当下重要性最高的需求。未来的县域消费市场，将更青睐那些能够提供高情感价值或高知识附加值，或者保持极致性价比的产品与服务。

医保部门也在鼓励基层就医。国家医保局17日披露，即将印发的按病种付费3.0版分组方案中，将推出158个基层病种，在不同等级的医疗机构执行相同的支付标准。按照DRG、DIP的支付改革思路，医疗机构获得同样的医保拨付额度，以激励基层就医。基层病种是指适合在符合条件的二级及以下医疗机构收治的常见病、多发病及部分慢性病病种，覆盖了基层日常诊疗最常面对的高血压、糖尿病、呼吸系统感染、颈腰背疾病、冠心病等，手术主要是一、二级，如阑尾切除术、腹股沟疝手术、肛周手术、骨科固定装置取出术。

我国公立医院收费实行省级政府指导价，从三级到一级医疗机构梯度递减，每级价差在10%到15%，部分操作复杂、难度较大、风险较高的手术，差距可扩大至30%到40%。报销比例则相反，从三级到一级的报销比例逐渐提高，起付线逐渐降低。同病同治同价后，医保部门对各级医疗机构预付的医保基金相同，意味着患者就医层级越低，治疗成本就越低，所在医疗机构获得盈余越多，以此鼓励上级医院减少不必要的小病治疗，将主要精力投入到疑难杂症和三、四级手术上，基层医疗机构也能借此增收。

分级诊疗已经喊了十几年，但是改革并不容易，上级医院缺乏下放小病患者的动力，基层机构也没有足够的能力承接转诊，只是被当作一个配药的场所。今年3月，国家医保局联合发改委、卫健委印发出台意见，提出医保基金预付和待遇报销向基层医疗机构倾斜，地方探索基层门诊按人头付费与慢病管理相结合、适宜基层的门诊支付方式。国家卫健委专家介绍，欧洲一些国家医保支付对分级诊疗是近乎强制的保证，如果不先由全科家庭医生首诊，将无法享受医保报销或比例明显下降，或是患者无法直接进入更高层级的医院就诊。英国医院通常不设置普通门诊，由家庭医生判断后才转诊至大型医院的专科，部分英国人购买商保并不是为了提高报销比例，主要目的是减少等待时间、更快见到专科医生。在美国就已选择相对自由的保险计划，保费更贵。在我国，基层医院的技术水平能否跟上则是患者的主要顾虑，不少人宁愿缴纳更高的医疗费用、接受报销比例更低，也要到三级医院看病。

国内的IIT，即研究者发起的临床研究，又出事了，不到一个月被曝光第三起患者死亡事件。8月18日，医药媒体Endpoints News报道，中国生物技术公司RiboX的CAR-T疗法RXIM002出现了受试者死亡事件，一名50多岁的硬皮病患者今年3月死于不良反应，但5个多月后被媒体询问才首次公开披露。RiboX 2021年成立，总部位于上海，主要开发环状RNA和体内CAR-T细胞治疗平台。出现死亡事件的研究2025年12月24日启动，计划纳入27名18到65岁患者，涉及系统性红斑狼疮、狼疮性肾炎、系统性硬化病、免疫性血小板减少症、特发性炎症性疾病、膜性肾病和自身免疫性溶血性贫血等疾病。8月8日，RiboX刚宣布其疗法RXIM002获得美国FDA批准开展首次临床试验。RiboX未公布该患者的具体死因，也未明确其死亡与疗法之间是否存在因果关系，而且患者死亡后未进行尸检，因此目前无法进一步判断其死亡主要与严重基础疾病有关，还是可能与疗法等技术因素有关。另一个争议点在于，试验的入组标准里明确如果有急性感染需要排除，但死亡患者入组时处于急性病毒感染、有心肌炎症状。让一位免疫系统已经因为病毒感染处于高负荷工作状态的患者接受CAR-T治疗是否明智，非常可疑。一般来说，即便已经上市的CAR-T治疗，用药前也要排除急性感染，只有等感染完全消退后才能做治疗。

死亡之外，争议集中在信息披露。7月23日，《科学》与撤稿观察联合披露了上海交大仇子龙团队与新华医院的一项IIT试验导致一名6岁女童死亡；8月5日，医药界媒体STAT曝光辉大基因去年8月的杜氏肌营养不良基因IIT试验中一名男童死亡。IIT是国内外医药界广泛存在的一种研究形式，因为会用到前沿疗法，本身就带有高风险的标签，而这几次死亡事件都在一开始就被隐匿了，这才是事件的核心。IIT最大的好处是快、花钱少，让不少中国生物制药企业获得了成本和速度优势，但如今因为安全监管和信息披露，可能面临信任危机。

最后是中国可重复使用火箭的好消息。时隔8个月，朱雀三号完成了上次未尽的任务。8月19日，蓝箭航天旗下朱雀三号遥二火箭发射升空，一二级分离后二级继续飞行，一级按照预定程序成功软着陆，这是我国首款成功入轨并实现了陆地回收的运载火箭，也一扫此前8月10日长征七号改火箭升空后爆炸解体带来的阴霾。蓝箭航天2015年成立，处于国内民营航天第一梯队。朱雀三号是中大型可复用火箭，采用液氧甲烷燃料和不锈钢箭体，直径4.5米，高76.6米，回收使用运载能力为12.5吨至18.3吨，不考虑回收单次低轨运载能力达21.3吨。去年12月朱雀三号首飞，一子级返回过程中再入点火正常，但之后出现异常燃烧，最终回收失败。

朱雀三号采用着陆支腿陆地回收模式，与SpaceX猎鹰9号一致，优点是方案成熟，回收平台地面准备较为简单，但需要火箭带着重2吨的着陆支腿占用运力。此前7月10日实现回收的长征十号，则是我国首例实现一子级回收的运载火箭，采用网系回收模式，相比当前主流回收方案，对火箭发动机推力调节和火箭落点偏差容错率更高。

蓝箭航天下一步将重点攻关重复使用。朱雀三号总设计师张晓东表示，SpaceX猎鹰9号经过12发火箭的验证，从半年以上的复用周期压缩到42天，这个过程花了三年半，蓝箭航天可能快一点，但也快不了多少，因为大量工作需要通过飞行试验来解决问题和优化设计。

近年以来，商业航天领域进展密集。SpaceX于6月上市纳斯达克，点燃了全球卫星组网热潮，中国也新增提交20.3万颗卫星部署申请，两大卫星互联网运营商星网与垣信已经申报近2.8万颗，其中垣信近日完成增资，引入18家投资者募资69.76亿，新增持股比例约13.94%，整体估值约500.5亿，低于此前拟募资最多150亿、估值最高达750亿的预期。

当前，国内运载火箭运载能力不足，发射周期长、成本高，成为行业发展瓶颈。按当前发射能力估算，星网需要42年建成，按期部署风险大。多家火箭企业都在集中攻关大运力、高可靠、低成本的液体燃料可回收火箭，年内多型火箭宣布首飞与回收试验计划。
