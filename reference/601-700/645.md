# 

大家好，我是小黛，欢迎来到第645期参考信息。中小学开学第一周，热点格外密集。8月30日，广西桂林网民发视频称，平乐县民族中学78名学生一间宿舍。视频中，宿舍是整体大开间，没有隔断，密密麻麻摆满上下铺，床挨床、人挨人，过道窄的仅能侧身经过。发视频的疑似为该校学生，称学校宿舍还没有建好，女生分配在体育馆，最多的区域为78人。引发关注后，教育局9月1日通报：因校内原有一栋学生宿舍楼存在安全隐患，今年7月拆除重建，同时在校内改造教室和体育馆作为新生过渡宿舍，因为条件限制未达标，承诺立即整改，三天内妥善就近安排高一新生到县城一所新建学校，加强安保及宿管值班职守，全面排查宿舍管理及安全隐患。

在湖南怀化，麻阳苗族自治县长河小学多位家长9月1日发视频称，开学了，自家四年级的孩子却没有教师上课。视频中，一大群身穿白红相间校服、佩戴红领巾的小学生坐在水泥地上围成一片。学校工作人员称，是因为一年级新生较多，开学后教员计划需新增一个班级，现有教室不够，于是各年级调整了教室位置，四年级两个班级受到影响，正准备启用行政楼的教室。当天教育局通报：为满足一年级扩招需求，学校对部分班级教室进行统筹调配，部分家长认为调整教室空间狭小，不认同调整方案，学校调研不充分、家校沟通不到位，未能充分兼顾各方诉求，引发矛盾。教育局、学校向学生和家长诚恳致歉，目前已经重新落实适宜教室并完成布置，9月2日可以正常开课。这个解释还是让人难以接受，网民疑问：报名时不知道这种情况吗？而且闹大之后，学校说准备启用行政楼的教室，之前没有考虑过吗？

在四川巴中，平昌县响滩中学家长反映，自家孩子报到时，班主任宣布要收取220元一年门禁费，家长质疑：进学校难道还要另外交钱？8月31日，教育科技局通报称，网传年收费220元为增值服务费，是该校为落实加强中小学生手机管理的要求，引入智慧校园服务第三方平台，基础权益免费、增值服务自愿付费。基础权益包括校园门禁通行、安全识别、学生考勤、在线请假等功能，所有学生家庭均可免费使用；增值服务包括信息推送、视频通话、家长留言等功能，每期120元或者每年220元，家长自愿选购。目前第三方平台已经停止该校相关业务，收取的增值服务费用已经全部退还。

在浙江台州，临海市哲商小学头门港学校新生入学要求家长填写工作单位、上传学历证明照片，并将在分班后逐一核对，引发争议后，教育局通报称，要求填报家长学历、毕业证书等信息超出了教育教学的必要范围，已责令学校整改，并对有关责任人严肃处理。由学生家庭信息调查引发的舆情并不少见，近年来几乎每逢开学都有类似的新闻爆出，屡屡引发争议。应该说，除少数要求填报家长职务、工作单位的学校，绝大多数学校摸排学生家庭信息，很大程度上是为了更好地开展家校互动，出发点是好的，至少不存在明显的主观恶意。但过度摸排频频引发争议，除了个别学校、老师别有用心，更深层原因在于没有统一标准：哪些信息应该填，哪些信息可以填也可以不填，全凭学校和老师自己设定、自己判断。当然不让填报，也架不住家长会自报家门。保定一中近日就有家长在家长群里称，自己是保定市人民医院纪委书记，孩子妈妈是保定学院人事处副处长，希望老师多关照自己的孩子。对此保定一中回应称，关注到此事，会对所有学生一视同仁。按说这种事即便要做，不也应该悄悄地进村吗？

9月1日，香港中文大学深圳开学典礼上，校长、中国工程院院士徐扬生分享了一个故事：一名湖南籍新生因为不满与排名相差10倍的同学住一间宿舍，而提出退学。原话是：有同学是2600名，我是260名，我怎么可以和他住在一个房间学习呢？徐扬生对这名同学说，你要看半年或者一年以后谁学得好，还不一定。不要看不起高考成绩不如自己的同学，也别再抱着过去的包袱较劲，人生就是这样，每一步都要靠自己去走，大家要放下过去的包袱，轻装上阵。南方日报评论：荒谬背后不仅是个别新生的优越感作祟，更蕴含着唯分数论对人的侵蚀。唯分数论逻辑下，分数排名始终是学生评价体系的核心标尺，部分学生更将其内化为价值判断标准，以此为基础定义自身和他人。话题冲上热搜后，引发关于优绩主义的讨论，不少人批评该学生思想僵化，感叹学生大多抱着优绩主义，还未经过社会的毒打。

国内最大电源换了。截至7月底，我国光伏发电装机容量达到12.86亿千瓦，占全国发电装机的31.5%；同期煤电装机12.85亿千瓦。光伏首次超过煤电，成为我国装机规模最大的电源品类，新能源从补充电源向装机主力转变。我国能源资源结构是富煤、贫油、少气，能源消费结构长期以煤为主，近十几年来在环境压力下加速转向多元化、清洁化。刚过去的“十四五”时期，光伏装机新增9.47亿千瓦，较2020年底增长约3.7倍。不过装机容量不等于实际发电能力，光伏发电受昼夜交替、气象条件的约束，间歇性、波动性特征明显，利用小时数远低于煤电。上半年煤电发电2.5万亿千瓦时，占总发电量比例首次低于一半，为49.7%，但仍远超光伏——1-7月光伏发电8024亿千瓦时，占全社会用电量的13%。同时，光伏制造业产能过剩问题依旧突出，而随着新能源发电项目全面进入电力市场，发电侧的市场化交易风险上升，部分项目投资收益承压，影响新增投资积极性。上半年光伏新增装机72.07吉瓦，同比大幅下降66%。光伏行业协会预测，全年新增装机180吉瓦到240吉瓦，下降24%-43%，将是2019年以来首次下降。压力反映在头部企业半年报中，就是走不出亏损泥潭：通威股份归母净亏51.19亿，同比扩大3.31%；隆基绿能归母净亏36.84亿，扩大43.4%。两家都表示，上半年产业链各环节开工率进一步降低，但行业整体供需失衡格局尚未根本改善，各环节产品价格维持低迷，企业经营压力凸显。

从中长期来看，国内能源转型还会加快。发改委指出，“十五五”及今后一段时间，是全球能源向低碳零碳转型的加速期。尤其今年，美以伊战争等地缘冲突持续扰动全球油气供应链，能源通道安全不确定性显著上升，倒逼各国加快以可再生能源替代化石能源。这个背景下，《可再生能源“十五五”规划》明确：到2030年，可再生能源发电总装机达到35亿千瓦，年发电量达到6万亿千瓦时，要求风电光伏发电装机达到28亿千瓦以上，占总装机比重超过一半。而截至2025年底，风光装机18.4亿千瓦，这意味着到2030年，风光装机还要再新增9.6亿千瓦，较2025年底增长约52%。

国内车市内卷，外溢到国外，主管部门希望引导车企在海外健康有序发展。商务部、工信部、市监总局9月1日联合出台《汽车行业境外竞争行为与合规建设指引》，主要包含规范境外市场竞争行为、提升境外本地化合规经营能力两方面。规范境外市场竞争主要针对定价层面，指引呼吁企业应依法依规做好零部件、整车等产品价格合规管理，不得获取不正当竞争优势、扰乱市场竞争秩序；同时应该避免因多频次、大幅度价格波动，影响境外消费者利益和品牌形象；还应依法合规进行透明清晰的标价，不违规在标价之外任意加价或收取未标明费用等。

中国车企曾在泰国大打价格战。2022年，泰国政府以新能源汽车购车补贴吸引海外车企，但要求享受补贴的车企在泰国落地产能，大批中国车企涌来，市场供给快速过剩，2024年泰国新能源车市已变成红海。泰国消费者此前对价格战比较陌生，中国品牌价格战引起市场抵触。2024年，比亚迪一款在售车型降价过快被约谈，作为补救，比亚迪承诺为受影响车主提供一年免费充电服务。目前泰国新能源汽车产能明显过剩，政府鼓励车企在泰国生产对外出口，价格战严重挤压企业盈利空间，也让中国品牌整体形象受到负面影响。

主管部门希望企业汲取经验，避免销售秩序混乱。中国汽车出海正在从最初级的整车贸易，逐步向深入本地化转型。指引提醒车企要因地制宜开展生产经营活动，确保全流程合规。企业应加强对东道国政治形势、宏观经济、社会安全、汽车产业等各方面的风险研判，完善生产安全事故应急处理预案，定期排查风险隐患，提高境外安全生产管理水平。劳工权益方面，应遵守东道国劳动法规，按照平等机会和公平待遇等原则招聘雇员，重视职业技能培训，畅通员工职业发展通道，完善员工权益保障机制。隐私保护方面，应采取必要措施，确保车联网、自动驾驶及数据跨境传输等活动合规。知识产权方面，企业应遵守中国和东道国关于知识产权保护的法律法规，加强自主知识产权境外市场布局和保护，还要规范外观设计、零部件生产、通信技术等领域的知识产权使用行为，妥善应对知识产权争议。

长期以来，中企出海会把在国内的思维也带出去，存在重政府关系、轻社会许可的问题。社会许可包括社区关系、工会制衡、NGO监督、环保评估、媒体舆论等。匈牙利是中企在欧洲投资的重点国家，今年多家汽车产业链企业遇挫，最新一个是宁德时代。豪伊杜-比哈尔州政府8月底要求，宁德时代工厂的电芯项目必须完成与镍暴露相关的所有职业安全缺陷整改，才能启动生产。2022年8月，宁德时代宣布计划投资73.4亿欧元在当地建厂，规划产能100吉瓦时，同时生产电池模组和电芯，产品主要供应奔驰和宝马在当地的工厂。今年下半年，电芯产线在调试等过程中发现镍暴露。镍暴露是指工人在生产环境中吸入或接触到含镍粉尘，超出职业接触限值。宁德时代回应匈牙利媒体称，依据法规自6月初起对工厂员工开展常态化生物暴露监测，8月初收到监测结果，发现9名员工镍暴露指标升高，随即主动上报。匈牙利监管机构先后三次到厂区检查，发现部分场景防护装备不足，8月25日要求多个车间停止作业，直到整改完成。此外，宁德时代工厂因违反多项环保规定被罚款1000万福林，约合21.3万人民币。

匈牙利交通与投资部长8月中旬表示，将修订对重点投资项目的监管规则，重点投资项目不再享有环保、自然保护和城市规划法规的豁免权，重点项目一旦违反环保法规，至少6个月不得获取新的施工许可或其他审批文件。首批受监管项目包括宁德时代、韩国三星和SK On三家电池工厂。近期还有两家中企被查罚：同在豪伊杜-比哈尔州的电池隔膜企业恩捷股份匈牙利子公司的工厂被要求暂停运营，原因是生产所用的金属元素泄漏至周边区域地下水，部分元素超标严重；比亚迪电动乘用车工厂被控在未完成法定检测的情况下，就将受污染的土壤倾倒至周边农田，罚款1000万福林，工厂原计划2025年四季度投产，现已推迟至2026年第四季度。

中企处境变化与匈牙利政局变动不无关系。连续执政16年的欧尔班今年选输下台，他鼓吹非自由民主，对华友好，任内亿纬锂能、恩捷股份等先后去投资建厂。新政府上台后回归欧盟主流。需要注意的是，环保及可持续发展诉求在当地长期存在，只是在欧尔班政府的议程中受到压制，一旦政府更迭，原本被压制或者边缘化的反对声音，极易迅速转化为监管行动。

星宇股份羞辱式劝退应届生的风波还在扩大。9月2日业绩说明会上，董事长兼总经理周小平回应称，企业高度重视，已公开发布致歉信，正在政府指导下妥善落实相关措施。但另一方面，官方通报中被停职的人力资源总监疑似查无此岗：星宇在近期港股招股书中披露的高管名单中，并无人力资源总监一职；执行董事及常务副总经理李树军负责业务运营及人力资源管理；官网公示的管理序列为“初级者——班长、组长——主任——部长——副总”，并没有总监层级。多名员工均表示，公司内部职级体系并未采用总监称谓。这个人力资源总监是不是实际职务，还有待进一步说明。

备受关注的还有外部核查。此前有应届生向港交所及部分车企供应链合规渠道反映，港交所称已将投诉递交至上市科，作为个案开展核查。还有学生称收到奔驰企业和人员保护办公室的回函，报告已转交专业团队进一步审查。大众方面已确认就相关投诉启动专项调查，并表示尊重劳动者合法权益是其恪守的核心原则，这一要求同样贯穿供应链体系。主流跨国车企普遍要求供应商完成可持续发展评估问卷（SAQ）并取得相应分数。SAQ是汽车行业合作联盟“驱动可持续发展”制定的，牵头运营的是欧洲企业社会责任协会，星宇大部分跨国车企客户都是成员；中企吉利、奇瑞、长城，吉利控股的沃尔沃、极星也是。联盟目标是让从事整车制造、零部件生产或提供配套服务的人员，都能够拥有体面工作条件，获得有尊严、受尊重的对待。

SAQ设置多个模块，包括公司管理、人权与工作条件、健康与安全、商业道德等，供应商需要作答，并提交原始证据支撑回答的内容。除了行业共识，一些国家也会提出要求。比如德国2023年生效的供应链尽职调查法，要求在德国拥有超过1000名员工的公司，都要对供应链进行尽职调查，包括不得雇佣童工、不得使用奴役、不得强迫劳动、不得使用不道德的安保服务、必须支付足够的报酬、尊重工会自由等。
